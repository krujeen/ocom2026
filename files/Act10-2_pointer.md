## ตอนที่ 2: เลือกคำตอบที่ถูกต้อง

คลืกเลือกคำตอบที่ถูกต้องที่สุดเพียงข้อเดียว

**ข้อ 2.1** ถ้า `int x;` อยู่ที่ที่อยู่ 0x200 และ `int *p = &x;` (int ขนาด 4 ไบต์) ค่าของ `p + 2` คือข้อใด

ก. 0x202 ข. 0x204 ค. 0x208 ง. 0x220

**ข้อ 2.2** คำสั่ง `int* a, b;` ข้อใดถูกต้อง

ก. a และ b เป็น pointer ทั้งคู่ ข. a เป็น pointer ส่วน b เป็น int ค. a เป็น int ส่วน b เป็น pointer ง. คอมไพล์ไม่ผ่าน

**ข้อ 2.3** ข้อใด **ไม่ถูกต้อง** เกี่ยวกับ reference

ก. ต้องกำหนดค่าตอนประกาศ ข. เปลี่ยนไปอ้างอิงตัวแปรอื่นได้ภายหลัง ค. ไม่สร้างกล่องใหม่ในหน่วยความจำ ง. ใช้งานเหมือนตัวแปรปกติ

**ข้อ 2.4** `arr[3]` มีความหมายเท่ากับข้อใด

ก. `*arr + 3` ข. `*(arr + 3)` ค. `&arr + 3` ง. `&(arr + 3)`

**ข้อ 2.5** ถ้า p เป็น pointer ชี้ไปที่ struct แล้ว `p->score` เท่ากับข้อใด

ก. `*p.score` ข. `(*p).score` ค. `&p.score` ง. `*(p.score)`

**ข้อ 2.6** เหตุใดคำสั่ง `scanf("%d", &x);` จึงต้องใส่ `&` หน้า x

ก. เพื่อให้โปรแกรมทำงานเร็วขึ้น ข. scanf ต้องรู้ที่อยู่ของ x เพื่อเขียนค่าลงไป ค. เพื่อแปลงชนิดข้อมูลของ x ง. ไม่จำเป็นต้องใส่ก็ได้

## ตอนที่ 4: เขียนฟังก์ชัน

เขียนฟังก์ชันตามที่กำหนด แล้วเขียน `main` เพื่อทดสอบ

**ข้อ 4.1** เขียนฟังก์ชันเพิ่มค่าตัวแปรขึ้น 1 จำนวน 2 แบบ

```typescript
void addOnePtr(int * x); // แบบ pointer
void addOneRef(int & x); // แบบ reference
```

ตัวอย่าง: `int a = 5; addOnePtr(&a); addOneRef(a);` แล้ว a มีค่า 7

**ข้อ 4.2** เขียนฟังก์ชันหาผลรวมและค่าเฉลี่ยของอาร์เรย์ โดยท่องอาร์เรย์ด้วย pointer

```typescript
void sumAndAvg(int a[], int n, long long &sum, double &avg);
```

ตัวอย่าง: a = {4, 7, 1, 8}, n = 4 ได้ sum = 20 และ avg = 5

**ข้อ 4.3** เขียนฟังก์ชันนับจำนวนเลขคู่และเลขคี่ในอาร์เรย์

```typescript
void countEvenOdd(int a[], int n, int &even, int &odd);
```

ตัวอย่าง: a = {3, 8, 5, 6, 10}, n = 5 ได้ even = 3 และ odd = 2

**ข้อ 4.4** เขียนฟังก์ชันเรียงค่าตัวแปร 3 ตัวจากน้อยไปมาก โดยแก้ค่าตัวแปรเดิม

```typescript
void sort3(int & a, int & b, int & c);
```

ตัวอย่าง: `int x = 9, y = 2, z = 5; sort3(x, y, z);` แล้วได้ x = 2, y = 5, z = 9

## ตอนที่ 5: โจทย์ประยุกต์

เขียนโปรแกรมให้สมบูรณ์ ทุกข้อ **ต้องท่องอาร์เรย์ด้วย pointer** ห้ามใช้ดัชนี `a[i]`

### ข้อ 5.1 กลับลำดับอาร์เรย์

กำหนดอาร์เรย์ขนาด N ให้กลับลำดับสมาชิกโดยใช้ pointer สองตัว ตัวหนึ่งเริ่มจากหัว อีกตัวเริ่มจากท้าย แล้วสลับค่าและขยับเข้าหากัน

- **ข้อมูลเข้า** บรรทัดแรกเป็นจำนวนเต็ม N บรรทัดที่สองเป็นจำนวนเต็ม N ตัว
- **ข้อมูลออก** สมาชิกหลังกลับลำดับ คั่นด้วยช่องว่าง
- **ข้อจำกัด** 1 ≤ N ≤ 100,000 และค่าแต่ละตัวอยู่ในช่วง −10^9 ถึง 10^9

| ข้อมูลเข้า    | ข้อมูลออก |
| ------------- | --------- |
| 5br>1 2 3 4 5 | 5 4 3 2 1 |
| 4br>7 -2 9 0  | 0 9 -2 7  |

### ข้อ 5.2 หมุนอาร์เรย์ไปทางซ้าย K ตำแหน่ง

กำหนดอาร์เรย์ขนาด N และจำนวนเต็ม K ให้หมุนอาร์เรย์ไปทางซ้าย K ตำแหน่ง สมาชิกที่หลุดจากด้านซ้ายจะวนไปต่อท้าย

- **ข้อมูลเข้า** บรรทัดแรกเป็น N และ K บรรทัดที่สองเป็นจำนวนเต็ม N ตัว
- **ข้อมูลออก** สมาชิกหลังหมุน คั่นด้วยช่องว่าง
- **ข้อจำกัด** 1 ≤ N ≤ 100,000 และ 0 ≤ K ≤ 10^9

| ข้อมูลเข้า    | ข้อมูลออก |
| ------------- | --------- |
| 5 2 1 2 3 4 5 | 3 4 5 1 2 |
| 3 7 10 20 30  | 20 30 10  |

คำใบ้: ใช้ฟังก์ชันกลับลำดับจากข้อ 5.1 สามครั้ง และสังเกตว่าหมุน N ครั้งได้อาร์เรย์เดิม

### ข้อ 5.3 รวมอาร์เรย์ที่เรียงแล้ว

กำหนดอาร์เรย์ A ขนาด N และอาร์เรย์ B ขนาด M ซึ่งเรียงจากน้อยไปมากแล้ว ให้รวมเป็นอาร์เรย์เดียวที่เรียงจากน้อยไปมาก โดยใช้ pointer ตัวหนึ่งเดินใน A และอีกตัวเดินใน B ห้ามใช้ `sort`

- **ข้อมูลเข้า** บรรทัดที่ 1 เป็น N บรรทัดที่ 2 เป็นสมาชิกของ A บรรทัดที่ 3 เป็น M บรรทัดที่ 4 เป็นสมาชิกของ B
- **ข้อมูลออก** สมาชิกที่รวมแล้ว N + M ตัว คั่นด้วยช่องว่าง
- **ข้อจำกัด** 1 ≤ N, M ≤ 100,000

| ข้อมูลเข้า     | ข้อมูลออก     |
| -------------- | ------------- |
| 31 4 742 3 8 9 | 1 2 3 4 7 8 9 |
| 25 531 5 6     | 1 5 5 5 6     |
