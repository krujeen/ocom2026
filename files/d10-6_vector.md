## ตอนที่ 1: vector คืออะไร และการประกาศ

**vector คืออาร์เรย์ที่ขยายและหดขนาดได้เอง** อยู่ในไลบรารี `<vector>` ข้อมูลเรียงติดกันในหน่วยความจำเหมือน array จึงเข้าถึงด้วย `v[i]` ได้เร็วเท่ากัน

### ทำไมต้องใช้ vector


|                            | array                                      | vector                     |
| -------------------------- | ------------------------------------------ | -------------------------- |
| ขนาด                       | ต้องกำหนดตอนเขียนโปรแกรม (`int a[100005]`) | เปลี่ยนได้ขณะรันโปรแกรม    |
| เพิ่มข้อมูลท้ายสุด         | ทำเองโดยเก็บตัวนับ                         | `v.push_back(x)`           |
| ทราบจำนวนสมาชิก            | ต้องเก็บตัวแปร n แยก                       | `v.size()`                 |
| ส่งเข้าฟังก์ชัน            | ต้องส่งขนาดไปด้วย                          | ส่งตัวเดียวจบ              |
| เรียงลำดับ                 | `sort(a, a+n)`                             | `sort(v.begin(), v.end())` |
| ใช้กับข้อมูลที่ไม่รู้จำนวน | ต้องจองเผื่อ ซึ่งสิ้นเปลืองหรือไม่พอ       | เหมาะที่สุด                |


**จุดที่ควรย้ำกับนักเรียน:** ถ้าโจทย์บอกว่า "มีข้อมูลหลายตัว แต่ไม่รู้ว่ากี่ตัว" หรือ "เก็บเฉพาะตัวที่เข้าเงื่อนไข" ให้นึกถึง vector ก่อนเสมอ

### วิธีประกาศ

```cpp
vector<int> a;              // vector ว่าง ขนาด 0
vector<int> b(5);           // ขนาด 5 ทุกตัวเป็น 0
vector<int> c(5, 7);        // ขนาด 5 ทุกตัวเป็น 7
vector<int> d = {3, 1, 4};  // กำหนดค่าเริ่มต้น
vector<int> e(d);           // คัดลอกจาก d (copy)
vector<long long> f;        // ชนิดอื่นก็ได้
vector<string> g;
```

**ข้อสังเกตสำคัญ:** `vector<int> b(5)` ในวงเล็บคือ "ขนาด" แต่ `vector<int> d = {5}` ในปีกกาคือ "ค่า" ที่ใส่เข้าไป 1 ตัว นักเรียนมักสับสนสองแบบนี้

### ตัวอย่างแรก: เทียบ array กับ vector

```cpp
int main() {
    int n;
    cin >> n;
    vector<int> v(n);          // จองขนาด n ตามที่รับมา
    for (int i = 0; i < n; i++) cin >> v[i];
    long long sum = 0;
    for (int i = 0; i < n; i++) sum += v[i];
    cout << sum << "\n";
}
```

โปรแกรมนี้ใช้ vector แบบ "แทน array" ตรง ๆ ข้อดีคือไม่ต้องเดาขนาดสูงสุดของ N

## ตอนที่ 2: pushback, popback, size, clear, empty

**ห้าคำสั่งนี้คือหัวใจของ vector** ใช้เก็บข้อมูลที่มีจำนวนไม่แน่นอนได้ทั้งหมด


| คำสั่ง                   | ความหมาย                          | ความเร็ว    |
| ------------------------ | --------------------------------- | ----------- |
| `v.push_back(x)`         | ต่อ x ท้าย vector                 | O(1) เฉลี่ย |
| `v.pop_back()`           | ลบตัวท้ายสุดทิ้ง (ไม่คืนค่า)      | O(1)        |
| `v.size()`               | จำนวนสมาชิกปัจจุบัน               | O(1)        |
| `v.empty()`              | คืน true ถ้าไม่มีสมาชิก           | O(1)        |
| `v.clear()`              | ลบสมาชิกทั้งหมด (size กลายเป็น 0) | O(n)        |
| `v.front()` / `v.back()` | ตัวแรก / ตัวสุดท้าย               | O(1)        |




### ภาพการทำงาน

```cpp
vector<int> v;          // v = []        size = 0
v.push_back(10);        // v = [10]      size = 1
v.push_back(20);        // v = [10 20]   size = 2
v.push_back(30);        // v = [10 20 30] size = 3
v.pop_back();           // v = [10 20]   size = 2
cout << v.back();       // 20
v.clear();              // v = []        size = 0
cout << v.empty();      // 1 (true)
```



### รูปแบบมาตรฐาน: รับข้อมูลโดยไม่รู้จำนวน

แบบที่ 1: รู้ N ล่วงหน้า แต่อยากใช้ pushback

```cpp
int n; cin >> n;
vector<int> v;
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    v.push_back(x);
}
```

แบบที่ 2: ไม่รู้ N อ่านจนข้อมูลหมด (ข้อสอบมักใช้เมื่อโจทย์บอกว่า "อ่านจนจบไฟล์")

```cpp
int x;
vector<int> v;
while (cin >> x) v.push_back(x);
```



### ข้อผิดพลาดที่พบบ่อย

- **ประกาศ** `vector<int> v(n)` **แล้วใช้** `push_back`**:** vector จะมี n ตัวที่เป็น 0 อยู่แล้ว ข้อมูลใหม่ต่อท้ายไป ทำให้ขนาดเป็น 2n ให้ใช้ `vector<int> v;` เปล่า ๆ แล้ว pushback อย่างเดียว หรือ `vector<int> v(n)` แล้วใช้ `v[i]` อย่างเดียว อย่าปน
- `pop_back()` **บน vector ว่าง:** พฤติกรรมไม่นิยามไว้ (โปรแกรมอาจพัง) ตรวจ `!v.empty()` ก่อนเสมอ
- `clear()` **ไม่ได้คืนหน่วยความจำ:** แค่ทำให้ size = 0 ซึ่งพอสำหรับการแข่งขัน



### ฝึกทันที: ข้อ 7 พิมพ์ย้อนกลับ

ให้นักเรียนลองเขียนเอง โดยใช้แค่ pushback และลูป `for (int i = (int)v.size() - 1; i >= 0; i--)` เฉลยอยู่ในส่วนเฉลยท้ายเอกสาร

## ตอนที่ 3: การเข้าถึงสมาชิก และ range-based for

**vector เข้าถึงสมาชิกด้วยเลขลำดับ (index) เหมือน array** โดยเริ่มที่ 0 และไปถึง `size() - 1`

### วิธีเข้าถึง

```cpp
vector<int> v = {5, 8, 2};
cout << v[0];        // 5 (เร็ว แต่ไม่ตรวจขอบเขต)
cout << v.at(1);     // 8 (ช้ากว่านิดหน่อย แต่ถ้าเกินขอบเขตจะ throw error ให้เห็นชัด)
cout << v.front();   // 5 เหมือน v[0]
cout << v.back();    // 2 เหมือน v[v.size()-1]
v[2] = 100;          // แก้ค่าได้
```

**คำแนะนำ:** ตอนฝึกหัดและดีบัก ใช้ `at()` จะเจอบั๊ก index เกินเร็วขึ้น ตอนแข่งใช้ `[]` ได้

### วนลูป 3 แบบ

**แบบที่ 1: ใช้ index** (ต้องใช้เมื่อต้องการรู้ตำแหน่ง)

```cpp
for (int i = 0; i < (int)v.size(); i++)
    cout << v[i] << " ";
```

**แบบที่ 2: range-based for** (สั้นที่สุด ใช้เมื่อไม่ต้องรู้ตำแหน่ง)

```cpp
for (int x : v)
    cout << x << " ";
```

**แบบที่ 3: range-based for แบบอ้างอิง** (ใช้เมื่อต้องการแก้ค่าในตัว vector จริง)

```cpp
for (int &x : v)
    x *= 2;           // v ทุกตัวถูกคูณ 2 จริง
```

ถ้าเขียน `for (int x : v) x *= 2;` ตัวแปร x เป็นสำเนา v จะไม่เปลี่ยน นี่คือจุดที่นักเรียนผิดบ่อยที่สุดของตอนนี้ ให้ทดลองรันเทียบกันให้เห็นกับตา


| ต้องการ                                         | เขียนแบบนี้                               |
| ----------------------------------------------- | ----------------------------------------- |
| อ่านค่าอย่างเดียว                               | `for (int x : v)`                         |
| แก้ค่าใน vector                                 | `for (int &x : v)`                        |
| อ่านข้อมูลก้อนใหญ่ เช่น string หรือ vector ซ้อน | `for (const auto &x : v)`                 |
| ต้องรู้ตำแหน่ง                                  | `for (int i = 0; i < (int)v.size(); i++)` |




### Iterator แบบพื้นฐาน (แค่ให้รู้จัก)

หลายฟังก์ชันของ vector ใช้ iterator เป็นตัวชี้ตำแหน่ง ให้จำแค่นี้ก่อน

- `v.begin()` ชี้ตัวแรก
- `v.end()` ชี้ "หลังตัวสุดท้ายหนึ่งช่อง" (ไม่ใช่ตัวสุดท้าย)
- `v.begin() + k` ชี้ตัวที่ k (นับจาก 0)

ใช้ร่วมกับ sort, erase, insert ในตอนถัดไป

### ฝึกทันที

ให้ต่อยอดข้อ 7: อ่านข้อมูล N ตัวด้วย pushback แล้วพิมพ์ย้อนกลับด้วย index (ลูปนับถอยหลัง) จากนั้นลองพิมพ์ซ้ำด้วย `reverse(v.begin(), v.end())` ซึ่งจะแนะนำต่อในตอนที่ 4

## ตอนที่ 4: sort, reverse, unique, erase, insert

**ฟังก์ชันจาก** `<algorithm>` **ใช้กับ vector ผ่าน iterator** รูปแบบเดียวกันทั้งหมดคือ `ฟังก์ชัน(v.begin(), v.end())` หมายถึงทำงานกับทั้ง vector

### sort: เรียงลำดับ

```cpp
vector<int> v = {5, 2, 9, 1};
sort(v.begin(), v.end());                 // น้อยไปมาก: 1 2 5 9
sort(v.begin(), v.end(), greater<int>()); // มากไปน้อย: 9 5 2 1
sort(v.begin(), v.begin() + 3);           // เรียงเฉพาะ 3 ตัวแรก
```

sort ใช้เวลา O(n log n) เปรียบเทียบกับ array คือ `sort(a, a + n)`

### reverse: กลับด้านลำดับ

```cpp
reverse(v.begin(), v.end());   // {1,2,5,9} กลายเป็น {9,5,2,1}
```



### unique: ตัดค่าซ้ำที่อยู่ติดกัน

**unique ตัดเฉพาะค่าซ้ำที่อยู่ติดกัน** จึงต้อง sort ก่อนเสมอ และ unique ไม่ลดขนาด vector เอง ต้องใช้คู่กับ erase เป็นสูตรสำเร็จดังนี้

```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
```


| ก่อน      | หลัง sort | หลัง erase(unique(...)) |
| --------- | --------- | ----------------------- |
| 3 1 3 2 1 | 1 1 2 3 3 | 1 2 3                   |


ให้นักเรียนจำเป็นสูตรสำเร็จ "sort → unique → erase" ใช้กับข้อ 4 ทันที

### erase: ลบสมาชิกตามตำแหน่ง

```cpp
vector<int> v = {10, 20, 30, 40, 50};
v.erase(v.begin() + 1);              // ลบตัวที่ index 1 -> 10 30 40 50
v.erase(v.begin() + 1, v.begin() + 3); // ลบช่วง [1,3) -> 10 50
```

**ข้อควรรู้:** erase กลางตัวต้องเลื่อนสมาชิกที่เหลือ จึงช้า O(n) ต่อครั้ง ถ้าลบเยอะ ๆ ในข้อมูลใหญ่ให้ระวัง TLE

### ลบตามค่า: erase + remove

```cpp
v.erase(remove(v.begin(), v.end(), 30), v.end());  // ลบทุกตัวที่มีค่า 30
```



### insert: แทรกสมาชิก

```cpp
vector<int> v = {1, 2, 4};
v.insert(v.begin() + 2, 3);   // แทรก 3 ที่ index 2 -> 1 2 3 4
```

insert กลางตัวก็เป็น O(n) เช่นกัน

### ฟังก์ชันช่วยที่ใช้บ่อยกับ vector


| ต้องการ                   | เขียน                                            | หมายเหตุ                       |
| ------------------------- | ------------------------------------------------ | ------------------------------ |
| ค่าน้อยสุด / มากสุด       | `*min_element(v.begin(), v.end())`               | ต้องมี เพราะคืน iterator       |
| ผลรวม                     | `accumulate(v.begin(), v.end(), 0LL)`            | ใช้ `0LL` เพื่อไม่ให้ overflow |
| นับจำนวนค่า x             | `count(v.begin(), v.end(), x)`                   | O(n)                           |
| หาว่ามี x ไหม             | `find(v.begin(), v.end(), x) != v.end()`         | O(n)                           |
| ค้นหาในข้อมูลที่เรียงแล้ว | `binary_search(v.begin(), v.end(), x)`           | O(log n)                       |
| ตำแหน่งแรกที่ ≥ x         | `lower_bound(v.begin(), v.end(), x) - v.begin()` | ต้อง sort ก่อน                 |




### ฝึกทันที

ให้ทำข้อ 1 (pushback และ sort), ข้อ 4 (ตัดค่าซ้ำ) ก่อน แล้วค่อยทำข้อ 9 (ลบค่าที่ซ้ำทั้งหมด) และข้อ 6 (erase) ซึ่งต้องใช้ความคิดมากขึ้น

## ตอนที่ 5: vector 2 มิติ, resize, assign

**vector 2 มิติคือ vector ที่สมาชิกแต่ละตัวเป็น vector อีกตัวหนึ่ง** จุดเด่นเหนือ array 2 มิติคือ "แต่ละแถวยาวไม่เท่ากันได้" (jagged array)

### resize และ assign


| คำสั่ง           | ผลลัพธ์                                                        |
| ---------------- | -------------------------------------------------------------- |
| `v.resize(n)`    | ปรับขนาดเป็น n ถ้าขยายจะเติม 0 ถ้าหดจะตัดตัวท้ายทิ้ง           |
| `v.resize(n, x)` | เหมือนข้างบน แต่ตัวที่เติมใหม่มีค่า x                          |
| `v.assign(n, x)` | ล้างของเดิมทั้งหมด แล้วสร้างใหม่ n ตัวค่า x ทุกตัว             |
| `v.reserve(n)`   | จองที่ไว้ล่วงหน้า (ไม่เปลี่ยน size) เพื่อให้ pushback เร็วขึ้น |


```cpp
vector<int> v = {1, 2, 3};
v.resize(5);          // 1 2 3 0 0
v.resize(2);          // 1 2
v.assign(4, 9);       // 9 9 9 9
```

**จุดที่ต้องย้ำ:** `resize` เปลี่ยนจำนวนสมาชิกจริง (`size()` เปลี่ยน) แต่ `reserve` ไม่เปลี่ยน size จึงใช้ `v[i]` ไม่ได้หลัง reserve อย่างเดียว

### แบบที่ 1: ตารางสี่เหลี่ยม N × M

```cpp
int n, m;
cin >> n >> m;
vector<vector<int>> g(n, vector<int>(m, 0));   // n แถว m หลัก ทุกช่องเป็น 0
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        cin >> g[i][j];
```

อ่านว่า "สร้าง vector ที่มี n ตัว โดยแต่ละตัวคือ vectorint> ขนาด m ค่า 0" ให้เขียนบนกระดานแยกชั้นให้ดู

### แบบที่ 2: แต่ละแถวยาวไม่เท่ากัน

```cpp
int n;
cin >> n;
vector<vector<long long>> g(n);      // n แถว แต่ทุกแถวว่างอยู่
for (int i = 0; i < n; i++) {
    int k;
    cin >> k;
    g[i].resize(k);                  // กำหนดความยาวแถว i
    for (int j = 0; j < k; j++) cin >> g[i][j];
}
```

หรือจะใช้ `g[i].push_back(x)` โดยไม่ต้อง resize ก็ได้ สองแบบให้ผลเหมือนกัน

ภาพในหน่วยความจำของ `g` เมื่อ n = 3:

```
g[0] -> 5 7 1
g[1] -> 2
g[2] -> 4 4 9 6
```



### การวนอ่านและพิมพ์ vector 2 มิติ

```cpp
for (int i = 0; i < (int)g.size(); i++) {
    for (int j = 0; j < (int)g[i].size(); j++)
        cout << g[i][j] << " ";
    cout << "\n";
}

// แบบสั้น
for (const auto &row : g) {
    for (long long x : row) cout << x << " ";
    cout << "\n";
}
```

สังเกตว่าความยาวแถวใช้ `g[i].size()` ไม่ใช่ m เพราะแต่ละแถวไม่เท่ากัน

### การใช้งานที่เกี่ยวข้อง: แบ่งข้อมูลเป็นกลุ่ม

เมื่อโจทย์ให้ "จัดข้อมูลเข้ากลุ่มตามเงื่อนไข" ให้สร้าง `vector<vector<int>> group(k)` แล้ว `group[เลขกลุ่ม].push_back(x)` ซึ่งเป็นแนวคิดของข้อ 5 และเป็นพื้นฐานของ adjacency list ในเรื่องกราฟ

### ฝึกทันที

ข้อ 2 (ผลรวมของแต่ละกลุ่ม) และข้อ 5 (แบ่งกลุ่มตามเศษ)

## ตอนที่ 6: ข้อควรระวังและความซับซ้อน

**ข้อผิดพลาดเกือบทั้งหมดของ vector มาจาก 5 เรื่องนี้** ควรทดลองรันให้นักเรียนเห็นผลจริงทีละเรื่อง

### 1. size() เป็นเลขไม่ติดลบ (unsigned)

```cpp
vector<int> v;                 // ว่าง
for (int i = 0; i < v.size() - 1; i++)   // ผิด! v.size()-1 กลายเป็นเลขมหาศาล
    cout << v[i];
```

`size()` คืนชนิด `size_t` ซึ่งไม่ติดลบ ถ้า size = 0 แล้วลบ 1 จะวนเกือบไม่รู้จบ วิธีแก้คือแปลงเป็น int ก่อนคือ `(int)v.size() - 1` หรือเปลี่ยนเงื่อนไขเป็น `i + 1 < (int)v.size()`

### 2. เข้าถึงเกินขอบเขต

`v[i]` เมื่อ i ≥ size หรือ i < 0 **ไม่แจ้ง error** อาจได้ค่าขยะหรือโปรแกรมพังแบบสุ่ม ตรวจ index ให้ดีหรือลองใช้ `at()` ตอนดีบัก

### 3. ส่ง vector เข้าฟังก์ชัน

```cpp
void f1(vector<int> v);            // คัดลอกทั้งหมด ช้า และแก้ไขไม่กระทบต้นฉบับ
void f2(vector<int> &v);           // ส่งอ้างอิง แก้ไขแล้วต้นฉบับเปลี่ยนด้วย
void f3(const vector<int> &v);     // ส่งอ้างอิงแบบอ่านอย่างเดียว (แนะนำสำหรับอ่านข้อมูล)
```



### 4. ลบสมาชิกระหว่างวนลูป

การ erase ในลูปที่ใช้ index ทำให้ตัวถัดไปเลื่อนมาแทนที่ตำแหน่งเดิม ถ้า `i++` ต่อไปจะข้ามข้อมูลหนึ่งตัว วิธีที่ปลอดภัยคือสร้าง vector ใหม่เก็บเฉพาะตัวที่ต้องการ แล้วค่อยแทนที่ (ใช้ในข้อ 9) หรือใช้ erase + remove

### 5. iterator ใช้ไม่ได้หลังแก้ขนาด

หลัง pushback หรือ erase ตัวชี้ที่เก็บไว้ก่อนหน้า (iterator) อาจใช้ไม่ได้แล้ว ให้เรียก `v.begin()` ใหม่ทุกครั้ง

### ความซับซ้อนของแต่ละคำสั่ง


| คำสั่ง                                | เวลา        |
| ------------------------------------- | ----------- |
| `v[i]`, `size()`, `front()`, `back()` | O(1)        |
| `push_back`, `pop_back`               | O(1) เฉลี่ย |
| `insert`, `erase` ตรงกลาง             | O(n)        |
| `erase` ท้าย vector                   | O(1)        |
| `clear`, `resize`, `assign`           | O(n)        |
| `sort`                                | O(n log n)  |
| `unique`, `reverse`, `find`, `count`  | O(n)        |




### ขนาดหน่วยความจำ

vectorint> หนึ่งตัวเก็บ 4 ไบต์ต่อตัว ถ้ามี 10 ล้านตัวใช้ประมาณ 40 MB ส่วน `long long` ใช้ 8 ไบต์ต่อตัว (ประมาณ 80 MB) ให้ประเมินข้อจำกัดหน่วยความจำของโจทย์ก่อนเสมอ

### ฝึกทันที

ข้อ 3 (ตัวหารทั้งหมด) เน้นเรื่อง n ใหญ่ และข้อ 8 (ตัวประกอบเฉพาะที่ไม่ซ้ำ) เน้นการเก็บเฉพาะค่าที่ต้องการลงใน vector

## โจทย์ฝึก 9 ข้อ

ข้อจำกัดของแต่ละข้อเป็นค่าที่ผมเสนอให้เหมาะกับการสอน (ไม่ได้มาจากข้อสอบจริง) ปรับตามความเหมาะสมได้ ทุกข้อทดสอบโค้ดเฉลยแล้ว

### ข้อที่ 1: pushback และ sort

**โจทย์:** รับจำนวนเต็ม N ตัว เก็บใน vector ด้วย pushback แล้วเรียงจากน้อยไปมากด้วย sort และพิมพ์

**ข้อมูลเข้า:** บรรทัดแรกคือ N บรรทัดที่สองคือจำนวนเต็ม N ตัว

**ข้อมูลออก:** จำนวนเต็มที่เรียงแล้ว คั่นด้วยช่องว่าง

**ข้อจำกัด:** 1 ≤ N ≤ 100,000 และ |ค่า| ≤ 10^9

```text
5
5 2 9 1 5
```

```text
1 2 5 5 9
```

**แนวคิด:** pushback ตามตอนที่ 2 แล้ว `sort(v.begin(), v.end())` ค่าซ้ำไม่ถูกตัด

### ข้อที่ 2: vector 2 มิติขนาดไม่เท่ากัน

**โจทย์:** มีกลุ่มข้อมูล N กลุ่ม กลุ่มที่ i มีข้อมูล ki ตัว (แต่ละกลุ่มยาวไม่เท่ากัน) เก็บใน `vector<vector<long long>>` แล้วพิมพ์ผลรวมของแต่ละกลุ่ม

**ข้อมูลเข้า:** บรรทัดแรกคือ N จากนั้น N บรรทัด แต่ละบรรทัดขึ้นต้นด้วย ki ตามด้วยข้อมูล ki ตัว

**ข้อมูลออก:** N บรรทัด บรรทัดที่ i คือผลรวมของกลุ่มที่ i (กลุ่มที่ ki = 0 ได้ 0)

**ข้อจำกัด:** 1 ≤ N ≤ 1,000, 0 ≤ ki ≤ 1,000 และ |ค่า| ≤ 10^12

```text
3
3 5 7 1
1 2
4 4 4 9 6
```

```text
13
2
23
```

**แนวคิด:** แบบที่ 2 ของตอนที่ 5 ใช้ `g[i].push_back(x)` และต้องใช้ `long long` เพราะผลรวมใหญ่เกิน int ได้

### ข้อที่ 3: ตัวหารทั้งหมด (n ใหญ่)

**โจทย์:** รับ n แล้วเก็บตัวหารทั้งหมดใน vector (วนถึง √n) จากนั้นเรียงและพิมพ์

**ข้อมูลเข้า:** จำนวนเต็ม n หนึ่งตัว

**ข้อมูลออก:** ตัวหารทั้งหมดของ n เรียงจากน้อยไปมาก คั่นด้วยช่องว่าง

**ข้อจำกัด:** 1 ≤ n ≤ 10^12

```text
36
```

```text
1 2 3 4 6 9 12 18 36
```

**แนวคิด:** ถ้า i หาร n ลงตัว แล้ว n/i ก็เป็นตัวหารด้วย วนแค่ i ถึง √n (ไม่เกิน 10^6 รอบ) ระวัง n เป็นกำลังสองสมบูรณ์ ต้องไม่ใส่ i ซ้ำสองครั้ง จึงต้องเรียงก่อนพิมพ์เพราะตัวหารคู่ใหญ่ถูกใส่ก่อน และตัวแปรต้องเป็น `long long`

### ข้อที่ 4: ตัดค่าซ้ำ

**โจทย์:** รับอาร์เรย์ N ตัว แล้วพิมพ์ค่าที่ไม่ซ้ำกันเรียงจากน้อยไปมาก

**ข้อมูลเข้า:** บรรทัดแรกคือ N บรรทัดที่สองคือจำนวนเต็ม N ตัว

**ข้อมูลออก:** ค่าที่ไม่ซ้ำกัน (แต่ละค่าพิมพ์ครั้งเดียว) เรียงจากน้อยไปมาก

**ข้อจำกัด:** 1 ≤ N ≤ 100,000 และ |ค่า| ≤ 10^9

```text
6
3 1 3 2 1 5
```

```text
1 2 3 5
```

**แนวคิด:** สูตร sort → unique → erase จากตอนที่ 4

### ข้อที่ 5: แบ่งกลุ่มตามเศษ

**โจทย์:** รับ N และ k แล้วรับจำนวนเต็มไม่ติดลบ N ตัว จัดกลุ่มตามเศษจากการหารด้วย k (กลุ่ม 0 ถึง k − 1) คงลำดับเดิมในกลุ่ม พิมพ์กลุ่มละบรรทัด ในรูป "เศษ: สมาชิก" (กลุ่มว่างพิมพ์เฉพาะ "เศษ:")

**ข้อมูลเข้า:** บรรทัดแรกคือ N และ k บรรทัดที่สองคือจำนวนเต็มไม่ติดลบ N ตัว

**ข้อมูลออก:** k บรรทัด บรรทัดที่ r ขึ้นต้นด้วย `r:` ตามด้วยสมาชิกในกลุ่มนั้นตามลำดับที่รับเข้ามา โดยมีช่องว่างหน้าสมาชิกแต่ละตัว

**ข้อจำกัด:** 1 ≤ N ≤ 100,000, 1 ≤ k ≤ 1,000 และ 0 ≤ ค่า ≤ 10^9

```text
7 3
4 7 9 3 10 6 5
```

```text
0: 9 3 6
1: 4 7 10
2: 5
```

**คำอธิบายตัวอย่าง:** เศษ 0 คือ 9, 3, 6 (ตามลำดับที่รับ) เศษ 1 คือ 4, 7, 10 เศษ 2 คือ 5

**แนวคิด:** สร้าง `vector<vector<int>> group(k)` แล้ว `group[x % k].push_back(x)` ลำดับเดิมคงอยู่เองเพราะ pushback ต่อท้ายตามลำดับที่รับ

### ข้อที่ 6: ผู้รอดชีวิตด้วย vector

**โจทย์:** คน N คนหมายเลข 1..N ยืนเป็นวงกลม เริ่มนับจากคนที่ 1 นับครบ K คัดคนนั้นออก แล้วเริ่มนับจากคนถัดไป จงหาผู้รอดคนสุดท้าย โดยใช้ vector และ erase

**ข้อมูลเข้า:** จำนวนเต็ม N และ K ในบรรทัดเดียว

**ข้อมูลออก:** หมายเลขของผู้รอดชีวิตคนสุดท้าย

**ข้อจำกัด:** 1 ≤ N ≤ 5,000 และ 1 ≤ K ≤ 10^9 (จำกัด N เพราะ erase แต่ละครั้งเป็น O(N) รวมเป็น O(N²))

```text
7 3
```

```text
4
```

**คำอธิบายตัวอย่าง:** คัดออกตามลำดับ 3, 6, 2, 7, 5, 1 เหลือคนที่ 4

**แนวคิด:** เก็บคนที่ยังอยู่ใน vector แล้วคำนวณตำแหน่งที่ถูกคัดออกด้วย `idx = (idx + K - 1) % p.size()` ซึ่งใช้เศษทำให้ K ใหญ่ถึง 10^9 ก็ไม่ต้องวนนับจริง หลัง erase ตำแหน่ง idx จะชี้คนถัดไปพอดี แต่ถ้า erase ตัวท้ายสุด idx จะเลยท้าย vector ต้องวนกลับเป็น 0

### ข้อที่ 7: พิมพ์ย้อนกลับด้วย vector

**โจทย์:** รับข้อมูล N ตัวเก็บใน vector แล้วพิมพ์ย้อนกลับ

**ข้อมูลเข้า:** บรรทัดแรกคือ N บรรทัดที่สองคือจำนวนเต็ม N ตัว

**ข้อมูลออก:** ข้อมูลทั้ง N ตัวในลำดับกลับด้าน คั่นด้วยช่องว่าง

**ข้อจำกัด:** 1 ≤ N ≤ 100,000 และ |ค่า| ≤ 10^9

```text
5
1 2 3 4 5
```

```text
5 4 3 2 1
```

**แนวคิด:** วนลูปนับถอยหลังจาก `size() - 1` ถึง 0 หรือใช้ `reverse` ก็ได้ ข้อนี้ใช้สอนจุดผิดบ่อยเรื่อง `size()` ที่เป็นเลขไม่ติดลบ

### ข้อที่ 8: ตัวประกอบเฉพาะที่ไม่ซ้ำ

**โจทย์:** รับ n แล้วเก็บตัวประกอบเฉพาะที่ไม่ซ้ำกันของ n ใน vector และพิมพ์เรียงจากน้อยไปมาก (ถ้า n = 1 พิมพ์ NONE)

**ข้อมูลเข้า:** จำนวนเต็ม n หนึ่งตัว

**ข้อมูลออก:** ตัวประกอบเฉพาะที่ไม่ซ้ำ เรียงจากน้อยไปมาก คั่นด้วยช่องว่าง หรือ `NONE` ถ้า n = 1

**ข้อจำกัด:** 1 ≤ n ≤ 10^12

```text
360
```

```text
2 3 5
```

**คำอธิบายตัวอย่าง:** 360 = 2³ × 3² × 5 มีตัวประกอบเฉพาะที่ไม่ซ้ำคือ 2, 3, 5

**แนวคิด:** วน p ตั้งแต่ 2 ถึง √n ถ้า p หาร n ลงตัวให้ pushback p แล้วหาร n ด้วย p ซ้ำจนหารไม่ลงตัว เมื่อวนจบถ้า n ยังมากกว่า 1 แปลว่าเหลือตัวประกอบเฉพาะตัวใหญ่อีก 1 ตัว ให้ pushback เพิ่ม ตัวประกอบที่ได้เรียงจากน้อยไปมากอยู่แล้วเพราะพบตามลำดับ

### ข้อที่ 9: ลบค่าที่ซ้ำทั้งหมด

**โจทย์:** รับอาร์เรย์ N ตัว ลบทุกค่าที่ปรากฏมากกว่า 1 ครั้งออกทั้งหมด แล้วพิมพ์ค่าที่เหลือตามลำดับเดิม ถ้าไม่เหลือพิมพ์ EMPTY

**ข้อมูลเข้า:** บรรทัดแรกคือ N บรรทัดที่สองคือจำนวนเต็ม N ตัว

**ข้อมูลออก:** ค่าที่ปรากฏเพียงครั้งเดียว ตามลำดับเดิมในอาร์เรย์ คั่นด้วยช่องว่าง หรือ `EMPTY` ถ้าไม่เหลือ

**ข้อจำกัด:** 1 ≤ N ≤ 100,000 และ |ค่า| ≤ 10^9

```text
7
4 1 4 2 3 2 5
```

```text
1 3 5
```

**คำอธิบายตัวอย่าง:** 4 และ 2 ปรากฏสองครั้ง จึงถูกลบทั้งหมด เหลือ 1, 3, 5

**แนวคิด:** ข้อนี้ต่างจากข้อ 4 ตรงที่ต้องรักษาลำดับเดิมและลบ "ทุกตัว" ของค่าที่ซ้ำ (ไม่เหลือตัวแทนไว้หนึ่งตัว) จึงเรียงสำเนาไว้นับจำนวนของแต่ละค่าด้วย `upper_bound - lower_bound` แล้วสร้าง vector ใหม่เก็บเฉพาะค่าที่นับได้ 1 ตามลำดับเดิม

## สรุป cheat sheet

**ใช้ vector เมื่อไม่รู้จำนวนข้อมูลล่วงหน้า ต้องการเพิ่ม/ลบตัวท้ายบ่อย หรือต้องการกลุ่มข้อมูลที่ยาวไม่เท่ากัน** ตารางนี้ให้นักเรียนถ่ายรูปหรือคัดลอกไว้ใช้ตอนฝึก


| งาน                                | โค้ด                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------- |
| ประกาศว่าง / ขนาด n / ขนาด n ค่า x | `vector<int> v;` / `v(n);` / `v(n, x);`                                   |
| เพิ่มท้าย / ลบท้าย                 | `v.push_back(x);` / `v.pop_back();`                                       |
| จำนวนสมาชิก / ว่างไหม / ล้าง       | `v.size()` / `v.empty()` / `v.clear()`                                    |
| ตัวแรก / ตัวสุดท้าย                | `v.front()` / `v.back()`                                                  |
| วนอ่าน / วนแก้ค่า                  | `for (int x : v)` / `for (int &x : v)`                                    |
| เรียงน้อยไปมาก / มากไปน้อย         | `sort(v.begin(), v.end());` / `sort(v.begin(), v.end(), greater<int>());` |
| กลับลำดับ                          | `reverse(v.begin(), v.end());`                                            |
| ตัดค่าซ้ำ (ต้อง sort ก่อน)         | `v.erase(unique(v.begin(), v.end()), v.end());`                           |
| ลบตำแหน่ง i / แทรกที่ตำแหน่ง i     | `v.erase(v.begin() + i);` / `v.insert(v.begin() + i, x);`                 |
| ลบทุกตัวที่มีค่า x                 | `v.erase(remove(v.begin(), v.end(), x), v.end());`                        |
| ปรับขนาด / สร้างใหม่               | `v.resize(n);` / `v.assign(n, x);`                                        |
| ตารางสี่เหลี่ยม n × m              | `vector<vector<int>> g(n, vector<int>(m));`                               |
| แถวยาวไม่เท่ากัน n แถว             | `vector<vector<int>> g(n); g[i].push_back(x);`                            |
| ส่งเข้าฟังก์ชันแบบอ่านอย่างเดียว   | `const vector<int> &v`                                                    |




### ข้อควรจำ 5 ข้อ

1. `v.size()` เป็นเลขไม่ติดลบ อย่าลบ 1 ตอน vector ว่าง ให้แปลงเป็น `(int)v.size()` ก่อน
2. `v[i]` ไม่ตรวจขอบเขต ตอนดีบักให้ลองใช้ `v.at(i)`
3. `vector<int> v(n)` แล้ว pushback จะได้ขนาด n + จำนวนที่ใส่ ให้เลือกใช้แบบใดแบบหนึ่งอย่าปน
4. ผลรวมหรือค่าที่อาจเกิน 2 × 10^9 ให้ใช้ `long long`
5. erase และ insert กลาง vector เป็น O(n) ถ้าข้อมูลใหญ่และต้องทำบ่อยให้หาวิธีอื่น เช่น สร้าง vector ใหม่
