## จุดประสงค์การเรียนรู้

ใบความรู้นี้ใช้ประกอบการเรียนเรื่องพอยน์เตอร์ ค่าย 1 สอวน. วิชาคอมพิวเตอร์ ปี 2569 เมื่อเรียนจบ นักเรียนสามารถ

1. อธิบายความหมายของ "ค่า" และ "ที่อยู่" ของตัวแปรในหน่วยความจำได้
2. ใช้ตัวดำเนินการ `&` และ `*` เพื่อหาที่อยู่และเข้าถึงข้อมูลผ่าน pointer ได้
3. ประกาศและใช้ pointer และ reference ได้ถูกต้อง
4. อธิบายความสัมพันธ์ระหว่าง pointer กับ array และท่องอาร์เรย์ด้วย pointer ได้
5. เขียนฟังก์ชันที่แก้ค่าตัวแปรที่ส่งเข้ามาได้ เช่น swap และฟังก์ชันที่คืนค่าหลายค่า
6. หลีกเลี่ยงข้อผิดพลาดที่พบบ่อยเมื่อใช้ pointer



## 1. หน่วยความจำและที่อยู่ของตัวแปร

ตัวแปรทุกตัวมีสองอย่างเสมอ คือ **ค่า (value)** ที่เก็บไว้ และ **ที่อยู่ (address)** ในหน่วยความจำ

ให้มองหน่วยความจำเป็นตู้ล็อกเกอร์ที่เรียงกันยาว ๆ แต่ละช่องจุได้ 1 ไบต์และมีหมายเลขประจำช่อง ตัวแปรหนึ่งตัวจองหลายช่องติดกันตามขนาดของชนิดข้อมูล ที่อยู่ของตัวแปรคือหมายเลขของช่องแรก


| ชนิดข้อมูล  | ขนาด (ไบต์) โดยทั่วไป |
| ----------- | --------------------- |
| `char`      | 1                     |
| `int`       | 4                     |
| `long long` | 8                     |
| `double`    | 8                     |


ตรวจสอบขนาดได้ด้วยตัวดำเนินการ `sizeof`

```cpp
int x = 42;
cout << sizeof(int) << "\n";   // 4
cout << sizeof(x) << "\n";     // 4
cout << sizeof(char) << "\n";  // 1
```

ตัวอย่าง: ถ้า `int x = 42;` เก็บอยู่ที่ช่อง 0x1000 ตัวแปร x จะใช้ช่อง 0x1000 ถึง 0x1003 ค่าของ x คือ 42 และที่อยู่ของ x คือ 0x1000 (ที่อยู่จริงเป็นเลขฐาน 16 ที่ยาวกว่านี้ และเปลี่ยนไปทุกครั้งที่รันโปรแกรม)

## 2. ตัวดำเนินการ & และ

pointer มีตัวดำเนินการหลักสองตัวที่ทำงานตรงข้ามกัน


| ตัวดำเนินการ | ชื่อ        | ความหมาย                                    |
| ------------ | ----------- | ------------------------------------------- |
| `&x`         | address-of  | ขอที่อยู่ (หมายเลขล็อกเกอร์) ของ x          |
| `*p`         | dereference | ไปที่ช่องที่ p ชี้ แล้วอ่านหรือแก้ค่าข้างใน |


```cpp
int x = 42;
cout << x  << "\n";   // 42
cout << &x << "\n";   // ที่อยู่ของ x เช่น 0x7ffd5c1a

int *p = &x;          // p เก็บที่อยู่ของ x (p ชี้ไปที่ x)
cout << *p << "\n";   // 42
*p = 100;             // แก้ค่าผ่าน pointer
cout << x  << "\n";   // 100
```

บรรทัด `*p = 100;` ไม่ได้แตะ x ตรง ๆ แต่ x เปลี่ยน เพราะ p ชี้ไปที่ x

**เครื่องหมาย  มีสองความหมาย** ขึ้นอยู่กับตำแหน่งที่ใช้

- ตอนประกาศ `int *p;` แปลว่า p เป็นตัวแปรที่เก็บที่อยู่ของ int
- ตอนใช้งาน `*p = 5;` แปลว่า ไปที่ช่องที่ p ชี้ แล้วใส่ 5 ลงไป

ข้อควรจำ: `*(&x)` ได้ x กลับมา เพราะ & กับ  หักล้างกัน

## 3. การประกาศและกำหนดค่าให้ pointer

รูปแบบ: `ชนิดข้อมูล *ชื่อตัวแปร = ที่อยู่;`

```cpp
int a = 10, b = 20;
int *p = &a;          // ชี้ไปที่ a
int *q = nullptr;     // ยังไม่ชี้ไปไหน
double d = 3.14;
double *pd = &d;      // ชนิดของ pointer ต้องตรงกับตัวแปรที่ชี้
p = &b;               // เปลี่ยนไปชี้ b ได้
cout << *p;           // 20
```

- ชนิดต้องตรงกัน: `int*` ชี้ได้เฉพาะ `int` ถ้าเขียน `double *pd = &a;` จะคอมไพล์ไม่ผ่าน
- pointer ที่ยังไม่มีเป้าหมาย ให้กำหนดเป็น `nullptr` ไว้ก่อนเสมอ
- pointer เปลี่ยนไปชี้ตัวแปรอื่นได้ทุกเมื่อ

**กับดักการประกาศหลายตัวพร้อมกัน** เครื่องหมาย  ผูกกับชื่อตัวแปร ไม่ใช่ชื่อชนิด

```cpp
int* p1, p2;    // p1 เป็น pointer แต่ p2 เป็น int ธรรมดา
int *p1, *p2;   // ถูกต้อง: pointer ทั้งคู่
```

**pointer ซ้อน pointer** คือ pointer ที่เก็บที่อยู่ของ pointer อีกตัว

```cpp
int x = 5;
int *p = &x;
int **pp = &p;   // pp ชี้ไปที่ p
cout << **pp;    // 5
```

เคล็ดลับ: ทุกครั้งที่ไล่โค้ด ให้วาดกล่องแทนตัวแปร เขียนค่าในกล่อง และวาดลูกศรจากกล่อง pointer ไปยังกล่องที่ถูกชี้

## 4. Reference (ตัวแปรอ้างอิง)

reference คือ "ชื่อเล่น" ของตัวแปรเดิม ไม่ได้สร้างกล่องใหม่ในหน่วยความจำ แก้ค่าผ่านชื่อไหนก็คือแก้ตัวเดียวกัน

```cpp
int x = 10;
int &r = x;    // r คือชื่อเล่นของ x
r = 20;
cout << x;     // 20
cout << (&r == &x);   // 1 (ที่อยู่เดียวกัน)

int &bad;      // ผิด! reference ต้องกำหนดค่าทันทีตอนประกาศ
```


| หัวข้อ                      | Pointer           | Reference           |
| --------------------------- | ----------------- | ------------------- |
| ต้องกำหนดค่าตอนประกาศ       | ไม่จำเป็น         | จำเป็น              |
| เปลี่ยนไปชี้ตัวอื่นได้      | ได้               | ไม่ได้              |
| เป็นค่าว่างได้              | ได้ (`nullptr`)   | ไม่ได้              |
| วิธีใช้งาน                  | ต้องเขียน `*p`    | ใช้เหมือนตัวแปรปกติ |
| สร้างกล่องใหม่ในหน่วยความจำ | ใช่ (เก็บที่อยู่) | ไม่ (เป็นชื่อเล่น)  |


ในการแข่งขันนิยมใช้ reference เพราะเขียนง่ายและผิดยาก แต่ต้องเข้าใจ pointer ด้วย เพราะ array, `scanf`, `sort` และ linked list ล้วนทำงานด้วยแนวคิดเรื่องที่อยู่

## 5. Pointer กับ Array และการท่องอาร์เรย์

**ชื่ออาร์เรย์ใช้แทนที่อยู่ของสมาชิกตัวแรกได้** และ **pointer arithmetic ขยับทีละสมาชิก ไม่ใช่ทีละไบต์**

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;        // เหมือน p = &arr[0];
cout << *p;          // 10
cout << *(p + 1);    // 20
cout << *(p + 3);    // 40
cout << p[2];        // 30 (ใช้ [] กับ pointer ได้)
```

ถ้า arr0 อยู่ที่ 0x100 แล้ว p + 1 จะเป็น 0x104 เพราะ int ขนาด 4 ไบต์ คอมไพเลอร์คำนวณขนาดให้เองตามชนิดของ pointer


| pointer | p     | p+1   | p+2   | p+3   | p+4   |
| ------- | ----- | ----- | ----- | ----- | ----- |
| สมาชิก  | arr0  | arr1  | arr2  | arr3  | arr4  |
| ค่า     | 10    | 20    | 30    | 40    | 50    |
| ที่อยู่ | 0x100 | 0x104 | 0x108 | 0x10c | 0x110 |


สูตรที่ต้องจำ

```
arr[i]   ≡  *(arr + i)
&arr[i]  ≡  arr + i
```

**การท่องอาร์เรย์ 3 แบบ**

```cpp
// แบบที่ 1: pointer + offset
for (int i = 0; i < n; i++)
    cout << *(arr + i) << " ";

// แบบที่ 2: เลื่อน pointer ไปเรื่อย ๆ
for (int *p = arr; p < arr + n; p++)
    cout << *p << " ";

// แบบที่ 3: range-based for กับ reference (แก้ค่าในอาร์เรย์ได้)
for (int &v : arr)
    v *= 2;
```

แบบที่ 3 ถ้าเขียน `for (int v : arr)` โดยไม่มี `&` ค่าในอาร์เรย์จะไม่เปลี่ยน เพราะ v เป็นเพียงสำเนา

**สิ่งที่นักเรียนใช้อยู่แล้วโดยไม่รู้ตัว**

```cpp
sort(arr, arr + n);   // arr + n ชี้ "เลยตัวสุดท้าย" ช่วง [arr, arr + n)
scanf("%d", &x);      // scanf ต้องการที่อยู่ จึงต้องใส่ &
int idx = lower_bound(arr, arr + n, 30) - arr;   // pointer ลบกันได้ระยะห่าง = ดัชนี
```

ข้อควรระวัง: ชื่ออาร์เรย์กำหนดค่าใหม่ไม่ได้ (`arr = p;` ผิด) และห้าม dereference `arr + n` เพราะเลยขอบอาร์เรย์

## 6. Pointer และ Reference กับการส่งค่าของฟังก์ชัน

การส่งตัวแปรเข้าฟังก์ชันมี 3 แบบ ต่างกันที่ว่าฟังก์ชันแก้ค่าตัวจริงได้หรือไม่

```cpp
void byValue(int x)      { x = 99; }   // แก้สำเนา ตัวจริงไม่เปลี่ยน
void byPointer(int *x)   { *x = 99; }  // แก้ผ่านที่อยู่
void byReference(int &x) { x = 99; }   // แก้ผ่านชื่อเล่น

int main() {
    int a = 1, b = 1, c = 1;
    byValue(a);       // a = 1
    byPointer(&b);    // b = 99 (ต้องส่ง &b)
    byReference(c);   // c = 99
}
```


| แบบ               | การประกาศพารามิเตอร์ | การเรียกใช้ | แก้ค่าตัวจริงได้ |
| ----------------- | -------------------- | ----------- | ---------------- |
| pass by value     | `int x`              | `f(a)`      | ไม่ได้           |
| pass by pointer   | `int *x`             | `f(&a)`     | ได้              |
| pass by reference | `int &x`             | `f(a)`      | ได้              |


**การส่งอาร์เรย์เข้าฟังก์ชัน** อาร์เรย์ถูกส่งเป็น pointer เสมอ จึงแก้ค่าได้ และฟังก์ชันไม่รู้ขนาด ต้องส่ง n ไปด้วย

```cpp
void fillzero (int a[], int n) {   // int a[] มีความหมายเท่ากับ int *a
    for (int i = 0; i < n; i++) a[i] = 0;
}
```

**เทคนิคการแข่งขัน** ส่ง `vector` หรือ `string` ขนาดใหญ่ด้วย `const &` เพื่อไม่ต้อง copy ข้อมูลทั้งก้อน ซึ่งช่วยไม่ให้โปรแกรมช้าจนเกินเวลา (TLE)

```cpp
long long sum(const vector<int> &v) {
    long long s = 0;
    for (int x : v) s += x;
    return s;
}
```



## 7. การประยุกต์ใช้ pointer



### 7.1 ส่งตัวแปรเข้าฟังก์ชันแบบแก้ค่าได้ เพื่อคืนค่าหลายค่า

`return` คืนได้ค่าเดียว ถ้าต้องการผลลัพธ์หลายค่า ให้ส่งตัวแปรรับผลเข้าไปแบบ reference

```cpp
void minMax(int a[], int n, int &mn, int &mx) {
    mn = mx = a[0];
    for (int i = 1; i < n; i++) {
        mn = min(mn, a[i]);
        mx = max(mx, a[i]);
    }
}
// เรียกใช้: int lo, hi; minMax(arr, n, lo, hi);
```



### 7.2 swap ด้วย pointer และ reference

```cpp
void swapPtr(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}
void swapRef(int &a, int &b) {
    int t = a; a = b; b = t;
}

int x = 3, y = 7;
swapPtr(&x, &y);   // x = 7, y = 3
swapRef(x, y);     // x = 3, y = 7
```

ถ้าเขียน `void swapWrong(int a, int b)` ค่าจะไม่สลับ เพราะฟังก์ชันสลับแค่สำเนา ในการแข่งขันใช้ `std::swap` ได้เลย

### 7.3 ท่องอาร์เรย์ด้วย pointer สองตัว (กลับลำดับอาร์เรย์)

```cpp
void reverseArr(int *l, int *r) {   // r ชี้ตัวสุดท้าย
    while (l < r) {
        swap(*l, *r);
        l++; r--;
    }
}
// เรียกใช้: reverseArr(arr, arr + n - 1);
```

ตัวอย่าง {1, 2, 3, 4}: รอบแรกสลับ 1 กับ 4 รอบที่สองสลับ 2 กับ 3 แล้ว l ไม่น้อยกว่า r จึงหยุด ได้ {4, 3, 2, 1} แนวคิดนี้เป็นพื้นฐานของเทคนิค Two Pointers

### 7.4 pointer กับ struct และตัวดำเนินการ ->

```cpp
struct Student { string name; int score; };
Student s = {"Jin", 85};
Student *p = &s;
cout << (*p).score;   // 85
cout << p->score;     // 85 (p->score เท่ากับ (*p).score)
```

ต้องมีวงเล็บใน `(*p).score` เพราะ `.` ทำงานก่อน `*`

### 7.5 การจองหน่วยความจำแบบไดนามิก

```cpp
int n; cin >> n;
int *a = new int[n];   // จองตามขนาดที่รับเข้ามา
// ... ใช้งาน a[i] ...
delete[] a;            // คืนหน่วยความจำ
```

ในการแข่งขันนิยมใช้ `vector` แทน แต่ `new` และ `->` เป็นพื้นฐานของ linked list และ tree ที่จะเรียนต่อไป

## 8. ข้อผิดพลาดที่พบบ่อยและสรุป


| ข้อผิดพลาด                        | ตัวอย่าง                            | วิธีแก้                                |
| --------------------------------- | ----------------------------------- | -------------------------------------- |
| pointer ไม่ได้กำหนดค่า            | `int *p; *p = 5;`                   | กำหนด `nullptr` หรือที่อยู่จริงก่อนใช้ |
| dereference ค่า nullptr           | `int *p = nullptr; *p = 1;`         | ตรวจ `if (p != nullptr)` ก่อน          |
| ลืม & ตอนเรียกฟังก์ชันแบบ pointer | `swapPtr(x, y);`                    | `swapPtr(&x, &y);`                     |
| ออกนอกขอบอาร์เรย์                 | `*(arr + n)` หรือ `p <= arr + n`    | ใช้เงื่อนไข `p < arr + n`              |
| คืนที่อยู่ของตัวแปร local         | `return &x;` เมื่อ x อยู่ในฟังก์ชัน | คืนเป็นค่า หรือส่ง reference เข้าไป    |
| ประกาศหลายตัวพร้อมกัน             | `int* a, b;`                        | `int *a, *b;`                          |
| ลืม `delete[]` หรือ delete ซ้ำ    | `new int[n]` แล้วไม่คืน             | ใช้ `vector` แทน                       |


ข้อผิดพลาด 1, 2 และ 4 มักทำให้เกิด Runtime Error (segmentation fault) เมื่อส่งโปรแกรมเข้าเกรดเดอร์ เมื่อเห็น RE ให้ตรวจ pointer และขอบอาร์เรย์ก่อน

**สรุปสิ่งที่ต้องจำ**


| สัญลักษณ์        | ความหมาย                                |
| ---------------- | --------------------------------------- |
| `&x`             | ขอที่อยู่ของ x                          |
| `*p`             | ไปที่ช่องที่ p ชี้                      |
| `int &r = x;`    | r เป็นชื่อเล่นของ x ใช้แก้ค่าในฟังก์ชัน |
| `arr[i]`         | เท่ากับ `*(arr + i)`                    |
| `p->x`           | เท่ากับ `(*p).x`                        |
| `[arr, arr + n)` | ช่วงครึ่งเปิดที่ฟังก์ชันใน STL ใช้      |
