# เอกสารประกอบการสอน std::pair

สอวน. ค่าย 1 วิชาคอมพิวเตอร์ · Oct 11, 2026 · @Krujeen

## 1. pair คืออะไร

`std::pair` เก็บข้อมูล 2 ค่าไว้ด้วยกันในตัวแปรเดียว โดยสองค่านั้นเป็นคนละชนิดกันได้ เช่น `pair<int, string>` ใช้ได้หลังจาก `#include <utility>` (ถ้าใช้ `<bits/stdc++.h>` จะมีอยู่แล้ว)

ปัญหาที่ pair ช่วยแก้ คือ เรียงค่าแล้วลืมว่าค่านั้นเดิมอยู่ตำแหน่งไหน

|  | อาร์เรย์ A = \[30, 10, 20\] | ผลหลัง sort |
| --- | --- | --- |
| เรียงเฉพาะค่า | 30, 10, 20 | 10, 20, 30 (ไม่รู้ว่า 10 เดิมอยู่ตำแหน่งที่เท่าไร) |
| จับคู่ (ค่า, ตำแหน่ง) ก่อน | (30,1), (10,2), (20,3) | (10,2), (20,3), (30,1) (ตำแหน่งเดิมติดไปกับค่า) |

สรุป: pair ทำให้ค่ากับข้อมูลที่เกี่ยวข้องกันเดินทางไปด้วยกันเสมอ

## 2. การสร้าง pair และการเข้าถึงข้อมูล

สร้าง pair ได้หลายแบบ ทุกแบบให้ผลเหมือนกัน เลือกแบบที่อ่านง่ายที่สุด ในการแข่งขันนิยมแบบ `{a, b}` เพราะสั้นที่สุด

```cpp
pair<int,int> p1;                   // ไม่ใส่ค่า ได้ (0, 0)
pair<int,int> p2(3, 5);             // ใส่ค่าตอนสร้าง
pair<int,string> p3 = make_pair(1, "abc");
pair<int,int> p4 = {7, 2};          // นิยมที่สุด
```

ข้อมูลสองค่าอยู่ในสมาชิก `first` (ค่าที่ 1) และ `second` (ค่าที่ 2) ซึ่งเป็นตัวแปรธรรมดา อ่านและแก้ได้ตรง ๆ ไม่มีวงเล็บ

```cpp
pair<int,int> p = {3, 5};
cout << p.first << " " << p.second;   // พิมพ์ 3 5
p.second = 10;                        // แก้ค่า ตอนนี้เป็น (3, 10)
cout << p.first + p.second;           // พิมพ์ 13
```

## 3. การเปรียบเทียบ pair

เปรียบเทียบ pair ด้วย `==`, `!=`, `<`, `>`, `<=`, `>=` ได้ทันที โดยเทียบ `first` ก่อน ถ้า `first` เท่ากันจึงเทียบ `second` (แบบพจนานุกรม) นี่คือเหตุผลที่ `sort` จัดเรียง pair ได้โดยไม่ต้องเขียนเงื่อนไขเพิ่ม

| นิพจน์ | ผล | เหตุผล |
| --- | --- | --- |
| (1,5) < (2,0) | true | first: 1 < 2 ตัดสินได้เลย |
| (2,3) < (2,4) | true | first เท่ากัน ดู second: 3 < 4 |
| (2,9) < (2,4) | false | first เท่ากัน ดู second: 9 > 4 |
| (2,4) == (2,4) | true | first และ second เท่ากันทั้งคู่ |

## 4. vector ของ pair: เก็บ รับ พิมพ์ และ sort

ใช้ `vector<pair<...>>` เก็บหลายคู่ แล้ว `v[i].first`, `v[i].second` คือค่าของคู่ที่ i ถ้าค่าอาจใหญ่เกิน 2 พันล้านให้ใช้ `long long`

```cpp
int n; cin >> n;
vector<pair<long long,long long>> v(n);
for (int i = 0; i < n; i++)
    cin >> v[i].first >> v[i].second;

sort(v.begin(), v.end());   // first น้อยไปมาก ถ้าเท่ากันดู second

for (auto &p : v)
    cout << p.first << " " << p.second << "\n";
```

เพิ่มคู่ทีละคู่ใช้ `v.push_back({a, b});` หรือ `v.emplace_back(a, b);` ถ้าใช้ C++17 ขึ้นไป อ่านค่าตอนวนลูปได้สั้นลงด้วย structured binding

```cpp
for (auto [x, y] : v) cout << x << " " << y << "\n";
```

ตัวอย่าง: รับ (3,5) (1,9) (3,2) (1,4) แล้ว sort ได้ (1,4) (1,9) (3,2) (3,5) คือจัดกลุ่มตาม first ก่อน แล้วในกลุ่มเดียวกันเรียงตาม second

## 5. เทคนิคจับคู่ (ค่า, ตำแหน่ง)

เก็บค่าคู่กับตำแหน่งเดิม `{x, i}` แล้ว `sort` ปกติ ตำแหน่งเดิมจะติดไปกับค่าเสมอ และเมื่อค่าเท่ากัน คู่ที่ตำแหน่งน้อยกว่าจะอยู่หน้าเองโดยไม่ต้องเขียนเงื่อนไขเพิ่ม

**เรียงน้อยไปมาก** (ข้อ 2)

```cpp
vector<pair<long long,int>> v;
for (int i = 1; i <= n; i++) {
    long long x; cin >> x;
    v.push_back({x, i});
}
sort(v.begin(), v.end());
for (auto &p : v) cout << p.second << " ";
```

ตัวอย่าง A = \[30, 10, 20, 10\] ได้คู่ (10,2) (10,4) (20,3) (30,1) พิมพ์ตำแหน่งได้ `2 4 3 1`

**เรียงมากไปน้อย แต่ตำแหน่งน้อยยังมาก่อน** (ข้อ 6) เก็บ `{-x, i}` แล้ว `sort` ปกติ ค่าที่มากกว่าจะกลายเป็นค่าติดลบที่น้อยกว่า จึงมาก่อน ส่วนตำแหน่งยังเรียงน้อยไปมากเหมือนเดิม

```cpp
for (int i = 1; i <= n; i++) {
    long long x; cin >> x;
    v.push_back({-x, i});     // กลับเครื่องหมายของค่า
}
sort(v.begin(), v.end());
for (auto &p : v) cout << p.second << " ";
```

ตัวอย่าง A = \[4, 7, 4, 7, 2\] ได้คู่ (-7,2) (-7,4) (-4,1) (-4,3) (-2,5) พิมพ์ตำแหน่งได้ `2 4 1 3 5` ถ้าต้องพิมพ์ค่าจริงกลับ ให้พิมพ์ `-p.first`

ข้อควรระวัง: ห้ามใช้ `greater<>()` กับคู่ (ค่า, ตำแหน่ง) เพราะตำแหน่งจะถูกเรียงมากไปน้อยตามไปด้วย

## 6. sort แบบกำหนดลำดับเอง (comparator)

ถ้าต้องการลำดับที่ต่างจากค่าเริ่มต้น ส่ง comparator เป็นอาร์กิวเมนต์ที่ 3 ของ `sort` มี 2 แบบที่ใช้บ่อย

```cpp
// 1) มากไปน้อย ทั้ง first และ second
sort(v.begin(), v.end(), greater<>());

// 2) second มากไปน้อย ถ้าเท่ากัน first น้อยไปมาก
sort(v.begin(), v.end(), [](auto &a, auto &b) {
    if (a.second != b.second) return a.second > b.second;
    return a.first < b.first;
});
```

comparator ตอบคำถามเดียวว่า a ต้องอยู่ก่อน b หรือไม่ ถ้า first ต่างกันก็ตัดสินได้ทันที ถ้าเท่ากันค่อยดูค่าถัดไป

**กฎสำคัญ** ใช้ `<` หรือ `>` เท่านั้น ห้ามใช้ `<=` หรือ `>=` เพราะเมื่อสองตัวเท่ากัน comparator ต้องตอบ false เสมอ ไม่เช่นนั้น `sort` อาจทำงานผิดหรือเกิด runtime error

`greater<>()` และ lambda แบบ `auto` ต้องใช้ C++14 ขึ้นไป ถ้าคอมไพเลอร์เก่ากว่านั้นให้เขียนชนิดเต็ม เช่น `greater<pair<int,int>>()`

## 7. เนื้อหาเสริม

| เครื่องมือ | ใช้ทำอะไร | ตัวอย่าง |
| --- | --- | --- |
| swap | สลับค่าสองคู่ทั้งก้อน | `swap(p1, p2);` |
| min / max | เทียบแบบพจนานุกรม | `max(make_pair(1,9), make_pair(1,4))` ได้ (1,9) |
| pair ซ้อน pair | เก็บ 3 ค่า | `pair<int,pair<int,int>> x;` ตัวในอยู่ที่ `x.second.first` |
| tuple | เก็บ 3 ค่าขึ้นไป | `tuple<int,int,int> t = {1,2,3};` อ่านด้วย `get<0>(t)` |
| set | เก็บคู่แบบเรียงลำดับ ไม่ซ้ำ | `set<pair<int,int>> s;` |
| priority\_queue | ดึงคู่ที่มากที่สุดก่อน | `priority_queue<pair<int,int>> pq;` ดูตัวบนด้วย `pq.top()` |
| map | สมาชิกของ map คือ pair | `for (auto &kv : m)` ใช้ `kv.first` เป็น key และ `kv.second` เป็น value |

เมื่อเรียนโครงสร้างข้อมูล set, map และ priority\_queue จะเจอ pair อีกหลายครั้ง

## 8. ข้อควรระวังและโค้ดที่ต้องจำ

- **ค่าใหญ่ใช้ long long** ถ้าค่าในโจทย์อาจเกิน 2 พันล้าน ให้ใช้ `pair<long long,long long>`
- **ติดลบเพื่อกลับลำดับ** เก็บ `-x` ต้องแน่ใจว่าค่าไม่ใช่ค่าต่ำสุดของชนิดนั้น เช่น `INT_MIN` เพราะ `-x` จะล้น
- **sort ไม่ stable** ค่าที่เท่ากันอาจสลับลำดับเดิม จึงใส่ตำแหน่งเป็นตัวตัดสิน หรือใช้ `stable_sort`
- **comparator ใช้ < หรือ > เท่านั้น** ห้ามใช้ `<=` หรือ `>=`

```cpp
pair<int,int> p = {a, b};            // สร้างคู่ อ่านด้วย p.first, p.second
vector<pair<int,int>> v;             // เก็บหลายคู่
v.push_back({a, b});                 // เพิ่มคู่
sort(v.begin(), v.end());            // first ก่อน แล้ว second
v.push_back({x, i});                 // จับคู่ (ค่า, ตำแหน่ง)
v.push_back({-x, i});                // เรียงค่ามากไปน้อย ตำแหน่งน้อยยังก่อน
```
