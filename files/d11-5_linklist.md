## บทนำ: Linked List คืออะไร

Linked List คือโครงสร้างข้อมูลที่เก็บข้อมูลเป็น **โหนด (node)** หลายตัวต่อกันเป็นสาย โดยแต่ละโหนดรู้ว่าโหนดถัดไปอยู่ที่ไหน ไม่จำเป็นต้องอยู่ติดกันในหน่วยความจำเหมือน array

ลองนึกถึงขบวนรถไฟ แต่ละตู้เก็บของ 1 อย่าง และมีตะขอเกี่ยวไปยังตู้ถัดไป เราถือแค่ **ตู้หัวขบวน** ก็เดินไปหาทุกตู้ได้ ตะขอก็คือ pointer และตู้หัวขบวนก็คือ `head`

```text
head
  |
  v
[ 10 | *]--->[ 20 | *]--->[ 30 | null ]
```

แต่ละกล่องมี 2 ช่อง คือ **ข้อมูล** (10, 20, 30) และ **ที่อยู่ของโหนดถัดไป** (`*`) โหนดสุดท้ายชี้ไป `null` เพื่อบอกว่าจบรายการ

### เปรียบเทียบกับ array

| เรื่อง | array | Linked List |
| --- | --- | --- |
| เข้าถึงตำแหน่งที่ i | ทันที (O(1)) | ต้องเดินจากหัว i ก้าว (O(i)) |
| เพิ่มหรือลบที่หัว | ต้องเลื่อนทุกตัว (O(N)) | แก้ pointer 2 จุด (O(1)) |
| ขนาด | กำหนดไว้ล่วงหน้า | โตได้ทีละโหนด |
| ตำแหน่งในหน่วยความจำ | ติดกัน | กระจายได้ |

สรุปง่ายๆ: ถ้าต้องเปิดดูตำแหน่งที่ i บ่อยๆ ใช้ array ถ้าต้องแทรกหรือลบกลางรายการบ่อยๆ ใช้ Linked List

### ก่อนเริ่ม ทบทวน pointer

- `int x = 5;` คือตัวแปรที่เก็บค่า 5
- `int* p = &x;` คือ p เก็บ **ที่อยู่** ของ x (`&x` แปลว่าที่อยู่ของ x)
- `*p` คือค่าที่อยู่ตรงที่ p ชี้ (ตอนนี้คือ 5)
- `nullptr` คือ pointer ที่ไม่ชี้ไปที่ใดเลย
- `p->val` คือเข้าถึงสมาชิก `val` ของ struct ที่ p ชี้ (เขียนเหมือน `(*p).val`)

### ลำดับการเรียนในเอกสารนี้

1. สร้างโหนดและต่อกัน
2. ท่องรายการ
3. เพิ่มและลบโหนด
4. กลับรายการ
5. Circular Linked List
6. std::pair และโจทย์ฝึก

## 1. Node แบบ struct + pointer

โหนด 1 ตัวคือ struct ที่มี 2 อย่าง คือ **ข้อมูล** และ **pointer ชี้ไปโหนดถัดไป**

```cpp
struct Node {
    int val;      // ข้อมูลที่เก็บ
    Node* next;   // ชี้ไปโหนดถัดไป
};
```

สังเกตว่า `Node` มี pointer ชนิด `Node*` อยู่ข้างใน ซึ่งทำได้เพราะ pointer มีขนาดคงที่ ไม่ได้ฝังโหนดทั้งตัวไว้

รายการทั้งหมดแทนด้วย pointer ตัวเดียวคือ `head`

```cpp
Node* head = nullptr;   // รายการว่าง: ยังไม่มีโหนดเลย
```

### กฎ 3 ข้อที่ต้องจำ

1. `head == nullptr` แปลว่า **รายการว่าง**
2. โหนดสุดท้ายต้องมี `next == nullptr` เสมอ
3. ถ้าทำ `head` หาย (ไม่มี pointer ตัวไหนชี้โหนดแรกอีก) เราจะเข้าถึงทั้งรายการไม่ได้อีกเลย

### ลองสร้างรายการ 2 โหนดด้วยมือ

```cpp
Node a{10, nullptr};
Node b{20, nullptr};
a.next = &b;      // a ชี้ไป b
Node* head = &a;  // หัวรายการคือ a
```

```text
head --> [ 10 | *]--->[ 20 | null ]
             a            b
```

วิธีนี้ใช้ได้กับตัวอย่างเล็กๆ แต่ในโจทย์จริงเราไม่รู้ล่วงหน้าว่าจะมีกี่โหนด จึงต้องสร้างโหนดตอนโปรแกรมรันด้วย `new` ซึ่งอยู่ในหัวข้อถัดไป

## 2. new / delete

`new` ขอหน่วยความจำสำหรับโหนดใหม่ตอนโปรแกรมรัน และ `delete` คืนหน่วยความจำนั้นเมื่อไม่ใช้แล้ว ทุก `new` ต้องมี `delete` คู่กัน 1 ครั้ง

```cpp
Node* n = new Node;   // ขอที่สำหรับโหนด 1 ตัว
n->val = 10;
n->next = nullptr;

// หรือเขียนรวบในบรรทัดเดียว
Node* m = new Node{20, nullptr};

delete n;   // คืนหน่วยความจำของ n
delete m;
```

### ฟังก์ชันสร้างโหนด (ใช้ซ้ำตลอดเอกสาร)

```cpp
Node* makeNode(int x) {
    return new Node{x, nullptr};
}
```

เขียนครั้งเดียวแล้วเรียกใช้ทุกครั้งที่ต้องการโหนดใหม่ โดยโหนดที่ได้จะมี `next` เป็น `nullptr` เสมอ จึงปลอดภัยต่อกฎข้อ 2 ในหัวข้อก่อนหน้า

### ข้อผิดพลาด 2 แบบที่เจอบ่อย

| ปัญหา | เกิดเมื่อไร | ผลที่ตามมา |
| --- | --- | --- |
| Memory leak | `new` แล้วไม่ `delete` หรือทำ pointer หายก่อนคืนที่ | หน่วยความจำเต็มเมื่อโหนดเยอะ |
| Dangling pointer | `delete p;` แล้วยังใช้ `p->val` ต่อ | ได้ค่าขยะหรือโปรแกรมพัง |

วิธีกันพลาด: หลัง `delete p;` ให้ตั้ง `p = nullptr;` ทุกครั้ง และก่อน `delete` โหนดที่อยู่กลางรายการต้องต่อ pointer ข้ามมันให้เรียบร้อยก่อนเสมอ (ดูหัวข้อ "ลบโหนด")

### เก็บกวาดทั้งรายการเมื่อจบโปรแกรม

```cpp
void clearList(Node*& head) {
    while (head) {
        Node* t = head;       // จำโหนดที่จะลบไว้
        head = head->next;    // ขยับ head ไปก่อน
        delete t;             // แล้วค่อยลบ
    }
}
```

ลำดับสำคัญมาก ถ้า `delete head` ก่อนขยับ เราจะอ่าน `head->next` จากที่ที่ถูกคืนไปแล้ว

> ในการแข่งขัน หลายครั้งไม่จำเป็นต้อง `delete` ตอนจบโปรแกรม เพราะระบบคืนหน่วยความจำให้เอง แต่ต้องฝึกเขียนให้ถูกเพื่อไม่เสียนิสัย และข้อที่ลบโหนดระหว่างโปรแกรมต้อง `delete` จริง

## 3. ท่องรายการ

การท่องรายการคือเริ่มที่ `head` แล้วเดินตาม `next` ไปเรื่อยๆ จนเจอ `nullptr` เป็นพื้นฐานของทุกอย่างที่เหลือ

```cpp
void printList(Node* head) {
    for (Node* p = head; p != nullptr; p = p->next) {
        cout << p->val << ' ';
    }
    cout << '\n';
}
```

อ่านเป็นภาษาคนได้ว่า "ให้ p เริ่มที่หัว ทำซ้ำตราบที่ p ยังไม่หมดรายการ แล้วขยับ p ไปโหนดถัดไป"

### ไล่ทีละก้าว

รายการ `10 -> 20 -> 30`

| รอบ | p ชี้ที่ | พิมพ์ | หลังขยับ p |
| --- | --- | --- | --- |
| 1 | โหนด 10 | 10 | ไปโหนด 20 |
| 2 | โหนด 20 | 20 | ไปโหนด 30 |
| 3 | โหนด 30 | 30 | p = nullptr |
| 4 | nullptr | ออกจากลูป |  |

### ใช้ท่องเพื่อนับและรวม

รูปแบบเดียวกัน เปลี่ยนแค่สิ่งที่ทำในลูป ซึ่งคือโจทย์ "นับและรวม"

```cpp
int cnt = 0;
long long sum = 0;
for (Node* p = head; p; p = p->next) {
    cnt++;
    sum += p->val;
}
```

`p` ในที่นี้เป็นแค่ตัวเดิน ไม่ใช่ `head` จึงห้ามเขียน `head = head->next` ในลูปท่อง เพราะจะทำให้ `head` เลื่อนจนเสียหัวรายการ

### สร้างรายการจากข้อมูล N ตัว (เพิ่มต่อท้ายทีละโหนด)

โจทย์ "สร้าง Linked List" ต้องรู้ตำแหน่งท้ายรายการ วิธีที่ง่ายและเร็วคือเก็บ `tail` ไว้อีกตัว

```cpp
Node* head = nullptr;
Node* tail = nullptr;
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    Node* nd = makeNode(x);
    if (head == nullptr) {      // โหนดแรก ทั้ง head และ tail ชี้ที่มัน
        head = tail = nd;
    } else {
        tail->next = nd;        // ต่อท้ายรายการเดิม
        tail = nd;              // tail ขยับมาที่โหนดใหม่
    }
}
printList(head);
```

จุดที่นักเรียนพลาดบ่อยคือลืมกรณี **โหนดแรก** ที่ `head` ยังเป็น `nullptr` อยู่ ถ้าเขียน `tail->next = nd` ตรงๆ โปรแกรมจะพัง

## 4. เพิ่มโหนด: หัว ท้าย กลาง

หลักเดียวที่ใช้ทุกกรณี: **ต่อโหนดใหม่เข้ากับของเดิมก่อน แล้วค่อยเปลี่ยนจุดที่ชี้มาหาโหนดใหม่** ถ้าสลับลำดับ เราจะทำให้รายการขาดและเสียโหนดที่เหลือไป

### 4.1 เพิ่มที่หัว

```cpp
void addHead(Node*& head, int x) {
    Node* n = makeNode(x);
    n->next = head;   // 1) ให้โหนดใหม่ชี้หัวเดิม
    head = n;         // 2) ย้ายหัวมาที่โหนดใหม่
}
```

```text
ก่อน:  head --> [20]--->[30]
1)     n --> [10]--->[20]--->[30]     (head ยังชี้ 20)
2)     head --> [10]--->[20]--->[30]
```

ใช้ได้แม้รายการว่าง เพราะ `n->next = head` จะเป็น `nullptr` พอดี ทำให้เพิ่มหัวไม่ต้องแยกกรณี

ถ้ารับข้อมูล 1 2 3 แล้วเพิ่มที่หัวทีละตัว รายการที่ได้คือ `3 -> 2 -> 1` (กลับลำดับ) ซึ่งคือโจทย์ "สร้างและพิมพ์รายการ"

### 4.2 เพิ่มที่ท้าย

วิธีที่ 1 ถ้ามี `tail` (ดูหัวข้อท่องรายการ) ใช้ `tail->next = n; tail = n;`

วิธีที่ 2 ถ้าไม่มี `tail` ต้องเดินไปหาโหนดสุดท้ายก่อน

```cpp
void addTail(Node*& head, int x) {
    Node* n = makeNode(x);
    if (head == nullptr) {      // รายการว่าง: โหนดใหม่คือหัว
        head = n;
        return;
    }
    Node* p = head;
    while (p->next != nullptr)  // หยุดที่โหนดสุดท้าย (ไม่ใช่ nullptr)
        p = p->next;
    p->next = n;
}
```

สังเกตเงื่อนไข `p->next != nullptr` ไม่ใช่ `p != nullptr` เพราะเราต้องการหยุด **ที่โหนดสุดท้าย** ไม่ใช่เดินเลยไปจนหลุด

### 4.3 เพิ่มตรงกลาง (แทรกหลังโหนดที่ k)

ตำแหน่งนับเริ่ม 1 และ k = 0 หมายถึงแทรกที่หัว

```cpp
void insertAfter(Node*& head, int k, int x) {
    if (k == 0) { addHead(head, x); return; }
    Node* p = head;
    for (int i = 1; i < k; i++)   // เดินไปให้ถึงโหนดที่ k
        p = p->next;
    Node* n = makeNode(x);
    n->next = p->next;   // 1) โหนดใหม่ชี้ตัวถัดไปของ p ก่อน
    p->next = n;         // 2) แล้วค่อยให้ p ชี้โหนดใหม่
}
```

```text
แทรก 99 หลังโหนด 20

เริ่มต้น:   [10]--->[20]--->[30]
1) n->next = p->next:   [99]---+
                               v
            [10]--->[20]--->[30]
2) p->next = n:   [10]--->[20]--->[99]--->[30]
```

**ถ้าสลับ 1) กับ 2)** คือทำ `p->next = n` ก่อน เราจะเสียที่อยู่ของ `[30]` ไปทันที เพราะไม่มี pointer ไหนชี้มันแล้ว รายการช่วงท้ายจึงหายทั้งหมด

### สรุปลำดับที่ปลอดภัย

| กรณี | ขั้นที่ 1 | ขั้นที่ 2 |
| --- | --- | --- |
| เพิ่มหัว | `n->next = head` | `head = n` |
| เพิ่มท้าย | `tail->next = n` | `tail = n` |
| แทรกหลัง p | `n->next = p->next` | `p->next = n` |

ทั้ง 3 กรณีเริ่มด้วยการให้โหนดใหม่ "จับ" ของเดิมไว้ก่อนเสมอ

## 5. ลบโหนด

การลบต้องมี **โหนดก่อนหน้า (prev)** มาข้ามโหนดที่จะลบ ก่อนแล้วค่อย `delete` เพราะ Linked List ชี้ได้ทางเดียว โหนดที่จะลบไม่รู้ว่าใครอยู่ข้างหน้ามัน

### 5.1 ลบโหนดแรกที่มีค่า x (ถ้าไม่มีไม่ต้องทำ)

แยกเป็น 3 กรณี

| กรณี | วิธี |
| --- | --- |
| รายการว่าง | ไม่ต้องทำอะไร |
| โหนดที่จะลบคือหัว | ย้าย `head` ไปโหนดถัดไป แล้ว `delete` |
| อยู่กลางหรือท้าย | `prev->next = cur->next` แล้ว `delete cur` |

```cpp
void delValue(Node*& head, int x) {
    Node* prev = nullptr;
    Node* cur = head;
    while (cur != nullptr && cur->val != x) {   // หาโหนดแรกที่ค่าเท่า x
        prev = cur;
        cur = cur->next;
    }
    if (cur == nullptr) return;     // ไม่พบค่า x หรือรายการว่าง
    if (prev == nullptr)
        head = cur->next;           // ลบที่หัว
    else
        prev->next = cur->next;     // ข้ามโหนด cur
    delete cur;
}
```

```text
ลบ 20:   prev        cur
          |           |
          v           v
   head->[10]------>[20]------>[30]

prev->next = cur->next:   [10]----------->[30]    ([20] ถูกข้าม)
delete cur:               [20] ถูกคืนที่
```

ลำดับสำคัญ ต้อง **ข้ามก่อน แล้วค่อย delete** ถ้า `delete cur` ก่อน เราจะอ่าน `cur->next` ไม่ได้อีก

ข้อสังเกต `prev == nullptr` หลังออกจากลูปแปลว่า `cur` ยังอยู่ที่หัว คือโหนดที่ต้องลบคือโหนดแรก จึงต้องแก้ `head` ไม่ใช่ `prev->next`

### 5.2 ลบโหนดที่ตำแหน่ง k

```cpp
void delAt(Node*& head, int k) {      // k เริ่มนับ 1 และรับประกันว่าถูกต้อง
    if (k == 1) {
        Node* t = head;
        head = head->next;
        delete t;
        return;
    }
    Node* prev = head;
    for (int i = 1; i < k - 1; i++)   // เดินไปหยุดที่โหนด k-1
        prev = prev->next;
    Node* t = prev->next;             // โหนดที่ k
    prev->next = t->next;
    delete t;
}
```

### 5.3 ลบทุกโหนดที่มีค่า x

ต่างจากข้อก่อนตรงที่ **ไม่หยุดหลังลบครั้งแรก** และห้ามขยับ `prev` เมื่อเพิ่งลบโหนด เพราะโหนดถัดไปอาจเป็นค่า x อีกตัว

```cpp
void delAll(Node*& head, int x) {
    // 1) ลบที่หัวซ้ำๆ จนหัวไม่ใช่ x
    while (head != nullptr && head->val == x) {
        Node* t = head;
        head = head->next;
        delete t;
    }
    // 2) ลบส่วนที่เหลือ
    Node* prev = head;
    while (prev != nullptr && prev->next != nullptr) {
        if (prev->next->val == x) {
            Node* t = prev->next;
            prev->next = t->next;   // ข้าม t แต่ยังไม่ขยับ prev
            delete t;
        } else {
            prev = prev->next;      // ขยับเฉพาะเมื่อไม่ได้ลบ
        }
    }
}
```

ตัวอย่างข้อมูลที่ต้องลองเสมอ: ค่า x ติดกันหลายตัว (`2 2 2`), x อยู่ที่หัว, x อยู่ที่ท้าย, ทุกตัวเป็น x (ผลลัพธ์ว่าง ต้องพิมพ์ `EMPTY`) และไม่มี x เลย

### คำสั่งแบบ add x / del x

โจทย์ที่รับคำสั่งทีละบรรทัดเอาฟังก์ชันข้างบนมาต่อกัน

```cpp
int q; cin >> q;
while (q--) {
    string cmd; int x;
    cin >> cmd >> x;
    if (cmd == "add") addHead(head, x);
    else               delValue(head, x);
}
if (head == nullptr) cout << "EMPTY\n";
else printList(head);
```

## 6. กลับรายการ

การกลับรายการคือกลับทิศของลูกศรทุกเส้น โดย **ไม่สร้างโหนดใหม่** ใช้ pointer 3 ตัวเดินไปพร้อมกัน

| ตัวแปร | หน้าที่ |
| --- | --- |
| `prev` | โหนดที่เดินผ่านมาแล้ว (ตอนแรกเป็น `nullptr`) |
| `cur` | โหนดที่กำลังแก้ |
| `nxt` | จำโหนดถัดไปไว้ก่อนแก้ ไม่งั้นทางไปต่อจะหาย |

```cpp
Node* reverseList(Node* head) {
    Node* prev = nullptr;
    Node* cur = head;
    while (cur != nullptr) {
        Node* nxt = cur->next;   // 1) จำตัวถัดไปไว้
        cur->next = prev;        // 2) กลับทิศลูกศร
        prev = cur;              // 3) ขยับ prev
        cur = nxt;               // 4) ขยับ cur
    }
    return prev;                 // prev คือหัวใหม่
}
// ใช้: head = reverseList(head);
```

### ไล่ทีละรอบ

รายการเริ่มต้น `1 -> 2 -> 3`

```text
เริ่มต้น:   prev=null   cur=[1]->[2]->[3]->null

รอบ 1: nxt=[2]   [1]->null            prev=[1]   cur=[2]
รอบ 2: nxt=[3]   [2]->[1]->null       prev=[2]   cur=[3]
รอบ 3: nxt=null  [3]->[2]->[1]->null  prev=[3]   cur=null

จบ: cur เป็น null ส่ง prev คือ [3] กลับเป็นหัวใหม่
```

ตัวที่ลืมกันบ่อยที่สุดคือบรรทัด 1) ถ้าเขียน `cur->next = prev` โดยไม่จำ `nxt` ไว้ก่อน เราจะไม่มี pointer ไปโหนดที่เหลืออีกแล้ว

ทดสอบเสมอกับรายการว่าง (ได้ว่าง) และรายการ 1 โหนด (ได้เหมือนเดิม) ซึ่งโค้ดข้างบนทำงานถูกโดยไม่ต้องแยกกรณี

## 7. Circular Linked List

Circular Linked List คือรายการที่ให้โหนดสุดท้ายชี้กลับมาที่หัว แทนที่จะชี้ `nullptr` ทำให้เดินวนได้ไม่รู้จบ เหมาะกับงานที่เป็นวงกลม เช่น คนยืนล้อมวง

```text
       +------------------------+
       v                        |
head->[1]--->[2]--->[3]--->[4]--+
```

### สร้างวงกลม

สร้างเหมือนรายการธรรมดาแล้ว **ปิดวงตอนท้าย** ด้วยบรรทัดเดียว

```cpp
// สร้างโหนด 1..n ต่อท้ายด้วย tail ตามปกติ แล้ว
tail->next = head;   // ปิดวง
```

### ข้อต่างที่ต้องระวัง

| เรื่อง | รายการธรรมดา | Circular |
| --- | --- | --- |
| โหนดสุดท้ายชี้ | `nullptr` | `head` |
| เงื่อนไขหยุดท่อง | `p != nullptr` | `p == head` อีกครั้ง |
| รายการว่าง | `head == nullptr` | `head == nullptr` |
| เหลือโหนดเดียว | `next == nullptr` | `next == ตัวเอง` |

ถ้าใช้เงื่อนไข `p != nullptr` กับวงกลม ลูปจะไม่จบเลย เพราะไม่มีโหนดไหนชี้ `nullptr`

### ท่องวงกลม

ใช้ `do-while` เพราะต้องพิมพ์โหนดแรกก่อนจึงเช็กว่ากลับมาที่หัวหรือยัง

```cpp
void printCircle(Node* head) {
    if (head == nullptr) return;
    Node* p = head;
    do {
        cout << p->val << ' ';
        p = p->next;
    } while (p != head);
    cout << '\n';
}
```

### ลบโหนดในวงกลม

ต้องมีโหนดก่อนหน้าเหมือนเดิม ข้อดีคือ **ทุกโหนดมีตัวก่อนหน้าเสมอ** ในวงกลม แม้เป็นโหนดหัว

```cpp
// prev ชี้โหนดก่อนหน้าของ cur
prev->next = cur->next;   // ข้าม cur
delete cur;
```

กรณีพิเศษคือเมื่อ **เหลือโหนดเดียว** (`prev == cur`) ให้ `delete cur` แล้วถือว่ารายการว่าง (`head = nullptr`) ไม่ต้องต่อ pointer ใดๆ

### โจทย์ตัวอย่าง: Josephus

คน N คนหมายเลข 1..N ยืนเป็นวงกลม เริ่มนับจากคนที่ 1 นับครบ K คัดคนนั้นออก แล้วเริ่มนับต่อจากคนถัดไป หาผู้รอดชีวิตคนสุดท้าย

**แนวคิด** ใช้ `prev` และ `cur` เดินไปทีละ K - 1 ก้าวเพื่อหยุดที่ตัวก่อนคนที่จะถูกคัด แล้วลบคนนั้นออกจากวง

```cpp
int josephus(int n, int k) {
    // สร้างวงกลม 1..n
    Node* head = makeNode(1);
    Node* tail = head;
    for (int i = 2; i <= n; i++) {
        tail->next = makeNode(i);
        tail = tail->next;
    }
    tail->next = head;            // ปิดวง

    Node* prev = tail;            // prev อยู่ก่อน cur เสมอ
    Node* cur = head;
    while (cur->next != cur) {    // ยังเหลือมากกว่า 1 คน
        for (int i = 1; i < k; i++) {   // นับ k คน: เดิน k-1 ก้าว
            prev = cur;
            cur = cur->next;
        }
        prev->next = cur->next;   // คัดคนที่ cur ชี้ออก
        delete cur;
        cur = prev->next;         // เริ่มนับใหม่จากคนถัดไป
    }
    int ans = cur->val;
    delete cur;
    return ans;
}
```

```text
N=5, K=2   วง: 1 2 3 4 5
คัด 2 -> เหลือ 1 3 4 5   (เริ่มนับที่ 3)
คัด 4 -> เหลือ 1 3 5     (เริ่มนับที่ 5)
คัด 1 -> เหลือ 3 5       (เริ่มนับที่ 3)
คัด 5 -> เหลือ 3
ผู้รอด = 3
```

ข้อควรระวัง: เงื่อนไขหยุดลูปคือ `cur->next == cur` (เหลือคนเดียว) ไม่ใช่ `nullptr`

## 8. std::pair (เนื้อหาเสริม)

`std::pair` คือกล่องเก็บข้อมูล 2 ค่าไว้ด้วยกัน อาจต่างชนิดกันก็ได้ ใช้แทนการเขียน struct เล็กๆ ที่มีแค่ 2 ช่อง ต้อง `#include <utility>` (หรือ `<bits/stdc++.h>`)

```cpp
pair<int, string> a = {101, "Somchai"};
cout << a.first << ' ' << a.second << '\n';   // 101 Somchai

auto b = make_pair(5, 7);     // pair<int,int>
b.first = 9;                  // แก้ค่าได้
```

- `first` คือค่าแรก และ `second` คือค่าที่สอง
- เปรียบเทียบด้วย `==`, `<` ได้เลย โดยเทียบ `first` ก่อน ถ้าเท่ากันค่อยเทียบ `second`
- `sort` กับ `vector<pair<...>>` จึงเรียงตาม `first` แล้วตาม `second` โดยอัตโนมัติ

```cpp
vector<pair<int,int>> v = {{3,1}, {1,9}, {3,0}};
sort(v.begin(), v.end());    // ได้ (1,9) (3,0) (3,1)
```

### ใช้ pair ร่วมกับ Linked List

**แบบที่ 1: โหนดเก็บข้อมูลเป็นคู่** เช่น (รหัส, คะแนน)

```cpp
struct Node {
    pair<int,int> data;   // data.first = รหัส, data.second = คะแนน
    Node* next;
};

Node* n = new Node{{101, 85}, nullptr};
cout << n->data.first << ' ' << n->data.second;
```

ข้อควรระวังคือต้องเขียน `n->data.first` เพราะ `->` ใช้กับ pointer ส่วน `.` ใช้กับตัวแปรปกติ

**แบบที่ 2: เก็บคำสั่งเป็นคู่** เหมาะกับโจทย์ที่รับ Q คำสั่ง

```cpp
vector<pair<string,int>> cmds;   // (ชื่อคำสั่ง, ค่า x)
for (int i = 0; i < q; i++) {
    string c; int x; cin >> c >> x;
    cmds.push_back({c, x});
}
for (auto& [c, x] : cmds) {      // structured binding (C++17)
    if (c == "add") addHead(head, x);
    else            delValue(head, x);
}
```

**แบบที่ 3: ฟังก์ชันคืนค่า 2 อย่าง** เช่น คืนทั้งหัวและท้ายของรายการที่สร้างเสร็จ

```cpp
pair<Node*, Node*> buildList(int n) {
    Node* head = nullptr; Node* tail = nullptr;
    // ... สร้างรายการ ...
    return {head, tail};
}
auto [h, t] = buildList(5);
```

> หัวข้อนี้เป็นเนื้อหาเสริม ขึ้นกับเวลาของค่าย ถ้าไม่พอสอนเฉพาะแบบที่ 1 และ `first/second` ก็เพียงพอสำหรับ 8 โจทย์ในเอกสารนี้

## 9. โจทย์ฝึก 8 ข้อ

เรียงจากง่ายไปยาก แต่ละข้อใช้ทักษะจากข้อก่อนหน้า ควรทำตามลำดับ

| ข้อ | โจทย์ | ทักษะหลัก | ระดับ | กลับไปอ่านหัวข้อ |
| --- | --- | --- | --- | --- |
| 1 | สร้าง Linked List | `new`, เพิ่มท้าย, ท่อง | พื้นฐาน | 2, 3 |
| 2 | สร้างและพิมพ์รายการ | เพิ่มหัว (ผลลัพธ์กลับลำดับ) | พื้นฐาน | 4.1 |
| 3 | นับและรวม | ท่องรายการ | พื้นฐาน | 3 |
| 4 | เพิ่มหัวและลบค่า | `add x` / `del x`, พิมพ์ `EMPTY` | ประยุกต์ | 4.1, 5.1 |
| 5 | ลบค่า x ทุกตัว | ลบหลายโหนดติดกัน, ลบที่หัวซ้ำ | ประยุกต์ | 5.3 |
| 6 | กลับรายการ | เปลี่ยน pointer ไม่สร้างโหนดใหม่ | ประยุกต์ | 6 |
| 7 | แก้ไขรายการตามคำสั่ง | `ins k x` / `del k` | ประยุกต์สูง | 4.3, 5.2 |
| 8 | Josephus | Circular Linked List | ประยุกต์สูง | 7 |

### แนวคิดและจุดที่ต้องระวังของแต่ละข้อ

**ข้อ 1 สร้าง Linked List** รับข้อมูล N ตัว เพิ่มต่อท้ายทีละโหนดแล้วพิมพ์ ใช้ `tail` เพื่อไม่ต้องเดินหาท้ายทุกรอบ ระวังกรณีโหนดแรกที่ `head` ยังเป็น `nullptr`

**ข้อ 2 สร้างและพิมพ์รายการ** เพิ่มที่หัวทีละตัว ค่าจะออกกลับลำดับจากที่รับ ซึ่งเป็นเรื่องปกติ ไม่ต้องแก้

**ข้อ 3 นับและรวม** ท่องรายการครั้งเดียว นับจำนวนและบวกค่า ใช้ `long long` สำหรับผลรวมถ้าค่าที่รับมีขนาดใหญ่

**ข้อ 4 เพิ่มหัวและลบค่า** `add x` คือเพิ่มหัว `del x` คือลบโหนดแรกที่มีค่า x ถ้าไม่มีไม่ต้องทำอะไร จบแล้วพิมพ์รายการ ถ้าว่างพิมพ์ `EMPTY` ระวังตอนลบที่หัว ต้องแก้ `head`

**ข้อ 5 ลบค่า x ทุกตัว** ลบทุกโหนดที่มีค่า x แล้วพิมพ์ ระวัง x ที่หัวติดกันหลายตัว และกรณีทุกตัวเป็น x (ต้องพิมพ์ `EMPTY`) อย่าขยับ `prev` ทันทีหลังลบ

**ข้อ 6 กลับรายการ** ใช้ `prev, cur, nxt` ห้ามสร้างโหนดใหม่ ระวังลืมจำ `nxt` ก่อนกลับทิศ

**ข้อ 7 แก้ไขรายการตามคำสั่ง** `ins k x` แทรกหลังโหนดที่ k (k = 0 คือแทรกที่หัว) และ `del k` ลบโหนดที่ k (นับเริ่ม 1) โจทย์รับประกันว่า k ถูกต้อง ระวังการ `del 1` ที่ต้องแก้ `head` และการแทรกหลังโหนดสุดท้าย

**ข้อ 8 Josephus** ใช้ Circular Linked List ตามหัวข้อที่ 7 ระวังเงื่อนไขหยุดและการเริ่มนับใหม่จากคนถัดไปของคนที่ถูกคัด

### ข้อมูลทดสอบที่ควรลองเองทุกข้อ

- รายการว่าง (หรือ N = 1)
- มีโหนดเดียว
- ค่าที่ต้องจัดการอยู่ที่หัว, กลาง, ท้าย
- ค่าซ้ำกันหลายตัวติดกัน
- ลบจนว่าง แล้วพิมพ์ `EMPTY`

## 10. ข้อผิดพลาดที่พบบ่อยและสรุป

เกือบทุกข้อผิดของ Linked List มาจาก 5 เรื่องนี้ ตรวจโค้ดตัวเองตามรายการก่อนส่ง

| ข้อผิดพลาด | อาการ | วิธีแก้ |
| --- | --- | --- |
| ใช้ `p->next` ตอน `p == nullptr` | โปรแกรมพัง (segmentation fault) | เช็ก `p != nullptr` ก่อนเข้าถึงสมาชิกเสมอ |
| ลืมกรณีรายการว่างหรือโหนดแรก | ผิดเฉพาะข้อมูลบางชุด | เขียนกรณี `head == nullptr` แยกก่อนเสมอ |
| ต่อ pointer ผิดลำดับ | รายการขาด โหนดท้ายหาย | ให้โหนดใหม่ชี้ของเดิมก่อน แล้วค่อยเปลี่ยนจุดที่ชี้มา |
| `delete` แล้วยังใช้โหนดนั้น | ค่าขยะ | ข้ามโหนดก่อน แล้วค่อย `delete` |
| ขยับ `head` ตอนท่อง | หัวรายการหาย พิมพ์ผิด | ใช้ตัวเดินแยก เช่น `p` |

### 3 คำถามเช็กตัวเองทุกครั้งที่แก้ pointer

1. หลังแก้แล้ว มี pointer ชี้โหนดที่เหลือครบทุกตัวหรือไม่
2. ถ้ารายการว่างหรือเหลือโหนดเดียว โค้ดยังทำงานถูกไหม
3. ถ้าโหนดที่แก้คือหัว (หรือท้าย) ต้องแก้ `head` (หรือ `tail`) ด้วยไหม

### วิธีฝึก

วาดภาพกล่องและลูกศรบนกระดาษทุกครั้งก่อนเขียนโค้ด แล้วไล่ทีละบรรทัดว่า pointer ไหนเปลี่ยน ใครชี้ใคร วิธีนี้ช่วยให้หาข้อผิดพลาดได้เร็วกว่าการอ่านโค้ดเฉยๆ มาก

### สรุปสั้นๆ

- โหนด = ข้อมูล + pointer ไปตัวถัดไป และ `head` คือทางเข้าเดียวของรายการ
- สร้างโหนดด้วย `new` และคืนที่ด้วย `delete`
- ท่องรายการด้วย `for (p = head; p; p = p->next)`
- เพิ่มโหนด: ให้โหนดใหม่ชี้ของเดิมก่อนเสมอ
- ลบโหนด: ใช้ `prev` ข้ามก่อน แล้วค่อย `delete`
- กลับรายการ: `prev, cur, nxt` และจำ `nxt` ก่อนกลับทิศ
- Circular: โหนดท้ายชี้หัว และหยุดท่องเมื่อกลับมาที่ `head`
